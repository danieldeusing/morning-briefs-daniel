# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub instead: **Security → Report a vulnerability**, or
[open a private advisory](https://github.com/danieldeusing/morning-briefs-daniel/security/advisories/new).

Say what is affected, how to reproduce it and what an attacker could do with it.
You get an answer within a week.

## Supported versions

Only the current site at [briefs.danieldeusing.de](https://briefs.danieldeusing.de) gets fixes.
