Der Schalter, der Claude Code die Hände bindet

Seit der Fassung 2.1.248, die releasebot.io auf heute datiert, gibt es --restricted (alternativ die Umgebungsvariable CLAUDE_CODE_RESTRICTED=1). Was der Schalter laut Original-Changelog tut, ist eine Liste aus fünf sehr bewusst gesetzten Punkten: Er entfernt alle eingebauten Werkzeuge, die Befehle oder Code ausführen, dazu WebFetch, sofern es nicht ausdrücklich in --tools steht. Er hält die Datei-Werkzeuge innerhalb des Arbeitsverzeichnisses. Er verweigert bypassPermissions. Und er ignoriert Benutzer-, Projekt- und lokale Einstellungsdateien.

Der letzte Punkt ist der, über den es sich nachzudenken lohnt. Die ersten drei nimmt man von jeder Sandbox an. Der vierte schließt die Tür, durch die eine Sandbox üblicherweise wieder aufgeht: Wenn ein .claude/settings.json im Repository die Berechtigungen erweitern dürfte, dann bestimmt am Ende genau das Projekt über den Käfig, das du gerade misstrauisch anschaust. Genau das geht jetzt nicht mehr. Der Unterschied zwischen „Sandbox" und „Sandbox mit einem Hebel, den der Prüfling bedient" ist der ganze Punkt der Übung.

Dieselbe Fassung bringt Diagnosen für server-verwaltete Einstellungen: eine Startwarnung plus eine erklärende Zeile in /doctor und /status, wenn diese nicht laden. Eine still fehlgeschlagene Richtlinie ist schlimmer als gar keine.

Das ist der Schlussstein von zehn Tagen Kleinarbeit. Am 18.08. (2.1.234) begannen Fern-Dateizugriffe, Sitzungs-Wiederherstellung, CLAUDE.md-Einbindungen und Datei-Uploads, Windows-NT-Namensraum-Pfade abzuweisen. Am 20.08. (2.1.238) bekamen Plugin-Marktplätze den headersHelper: ein Befehl, der kurzlebige HTTP-Header für Katalog-Abrufe erzeugt, statt dass der Abruf Zugangsdaten aus der Umgebung erbt.

Der \??\-Pfad: Windows kennt neben dem Pfad, den du kennst (C:\tmp), noch eine Adressform eine Ebene tiefer im Betriebssystem, die mit \??\ beginnt. Das ist wie eine Hausnummer, die nicht auf dem Straßenschild steht, aber trotzdem funktioniert — Prüfungen, die nur die Straßenschilder kennen, laufen daran vorbei. Wird so ein Pfad auf eine Netzwerkfreigabe gelenkt, meldet Windows sich dort automatisch an und schickt dabei einen Anmelde-Fingerabdruck (den NTLM-Hash) mit. Ein Angreifer, der dich dazu bringt, „nur eine Datei zu lesen", bekommt so deine Anmeldedaten geschenkt. Deshalb ist „diese Pfadform wird gar nicht erst angenommen" die richtige Antwort und nicht „wir prüfen sie sorgfältiger".

Meine Lesart, und ich verteidige sie: Das ist Claude Code auf dem Weg vom Einzelplatz-Werkzeug zu etwas, das in fremden Organisationen und auf fremdem Code läuft. Für dich praktisch heißt das: Try Nimm --restricted, wann immer du Claude Code auf ein Repository loslässt, das du nicht selbst geschrieben hast — ein fremder Pull Request, ein Open-Source-Projekt, das du bewertest, ein Kundenstand beim ersten Kontakt. Der Modus kostet dich nichts, solange du ohnehin nur lesen und verstehen willst. Und die ehrliche Einschränkung dazu: Das ist ein Modus, kein Gefängnis. Er reduziert die Angriffsfläche des Werkzeugs; er ersetzt nicht die Prozess- oder Container-Grenze darum herum.

75 statt 340 Megabyte

Die unspektakulärste Änderung der Woche ist die, die du am schnellsten merkst. Fassung 2.1.239 (22.08.) komprimiert das native Binary mit zstd: rund 75 MB statt 340 MB auf Linux x64, dazu etwa 2 MB weniger, weil eingebettete Skill- und Prompt-Texte kompakter abgelegt werden. Das betrifft Erstinstallation und jedes automatische Update.

Wichtiger für den Alltag ist aber die Fassung 2.1.243: Code wird jetzt bei Bedarf nachgeladen, statt das gesamte Bundle dauerhaft im Speicher zu halten — laut Changelog rund 40–70 MB weniger je Sitzung. Wer die eigene Arbeit über mehrere parallele Sitzungen verteilt, und genau dazu lädt das ganze Subagenten-Muster ein, holt sich damit auf demselben Laptop zwei bis drei Sitzungen mehr heraus.

Im selben Zug behoben: entfernte MCP-Server in nicht-interaktiven -p- und SDK-Sitzungen erholten sich nie von einer abgerissenen Verbindung; sie verbinden sich jetzt neu oder melden sich sauber als fehlgeschlagen. Das ist der Fehler, den man bisher dem eigenen Server angelastet hat. Und Fassung 2.1.245 räumt einen Startabsturz auf Distributionen mit glibc 2.44 weg (Arch, CachyOS, Fedora Rawhide).

Entfernter MCP-Server: Das Model Context Protocol ist die Steckdosenleiste zwischen einem KI-Werkzeug und allem, was es bedienen soll. „Entfernt" heißt: Die Steckdose steht nicht auf deinem Rechner — und reißt die Leitung dorthin ab, ohne dass es jemand merkt, arbeitet der Agent munter weiter, nur eben ohne Werkzeug.

Anthropics Scanner bekommt das große Modell — und keine eigene Rechnung

Das Claude-Security-Plugin lief hier am 23.08. schon einmal als Kurznotiz. Der Nachtrag ist die interessantere Hälfte: Seit dem 21.08. laufen die Enterprise-Repository-Scans auf Claude Mythos 5. Jeder Befund trägt eine CWE-Kategorie, eine Vertrauens- und eine Schweregrad-Einstufung sowie einen Behebungsvorschlag, der sich direkt in Claude Code im Browser öffnen lässt.

Der Satz, der mehr wert ist als das Modell-Upgrade, steht daneben: Die Scans werden als normaler Token-Verbrauch im bestehenden Tarif abgerechnet — kein separates Zusatzprodukt, keine eigene Lizenz. Sicherheits-Scanning wird traditionell pro Sitzplatz oder pro Repository verkauft. Über Token abgerechnet skaliert der Preis stattdessen mit dem, was du tatsächlich prüfst. Für einen Ein-Personen-Laden ist das der Unterschied zwischen einer Lizenz, die man sich nicht rechtfertigen kann, und ein paar Euro für einen tiefen Durchlauf über ein Repository.

Zwei-von-drei-Prüfung: Ein Kandidat-Befund wird an drei unabhängige Prüfer weitergereicht, jeder mit einer anderen Brille: Erreichbarkeit („kommt ein Angreifer überhaupt an diese Codestelle?"), Auswirkung („und was passiert, wenn doch?") und Abwehr („blockt weiter vorne schon etwas?"). Erst wenn zwei der drei zustimmen, wird gemeldet. Das ist der Unterschied zwischen einem Sicherheitswerkzeug und einer Fehlalarm-Maschine: Nicht die Fähigkeit, etwas Verdächtiges zu finden, ist knapp, sondern die Bereitschaft, das meiste davon wieder wegzuwerfen.

Quellenlage, ehrlich: Der Mythos-5-Wechsel und die Abrechnungsregel stammen aus einer einzelnen Sekundärquelle, deren Artikel selbst kein Datum ausweist; Anthropics Produktseite habe ich heute nicht abgerufen. Die Architektur — Orchestrator auf Opus, Kartograf und Nur-Lese-Explorer auf Sonnet, drei Prüfer-Brillen — ist über einen Bericht vom 22.07. belegt. Plausibel also, aber einfach belegt.

Vier Agenten ziehen in den Gruppenchat

Slack hat am 20.08. Slack Code gestartet: Coding-Agenten laufen in eigens dafür angelegten Kanälen — namentlich Claude Code, Cognitions Devin, GitHub Copilot und Vercels Agent. Verfügbar ist das auf jedem Slack-Tarif; den Zugang zu den Agenten selbst musst du separat haben.

Nicht zu verwechseln mit GitHubs eigener Slack-Vorschau vom 21.08., die hier am 25.08. stand. Der Unterschied ist die Blickrichtung: Dort stellt ein Anbieter seinen Agenten in einen fremden Chat. Hier baut Slack den Behälter und lädt vier Konkurrenten hinein.

Meine Sicht: Das Interessante ist nicht der Chat, es sind die Reiter. Plan, Diff und Vorschau als gleichberechtigte Flächen sind eine Harness-Oberfläche — und wenn vier konkurrierende Agenten in dieselbe Oberfläche zeichnen, geht die Wechselhürde zwischen ihnen gegen null. Für dich als Nutzer ist das gut. Für jeden Anbieter, dessen Burggraben die eigene Oberfläche war, ist es schlecht. Die aufschlussreiche Frage der nächsten Monate lautet deshalb, wer als Erster nicht mehr dort hineinzeichnen will.

Zwei Vorbehalte: „Gratis auf allen Tarifen" ist der Anschaffungspreis, nicht der Betriebspreis. Und dein Diff wandert in die Aufbewahrungsregeln eines Chat-Produkts — wer Kundencode anfasst, klärt das vor dem ersten Kanal, nicht danach.

Anthropics Sicherheits-Scanner für Claude Code läuft seit dem einundzwanzigsten August in der Firmenkunden-Variante auf dem großen Modell, und der wichtigere Satz daneben lautet: Die Scans werden als normaler Token-Verbrauch im bestehenden Tarif abgerechnet, ohne Zusatzprodukt. Sicherheits-Scanning wird sonst pro Sitzplatz verkauft. Über Token abgerechnet skaliert der Preis mit dem, was du tatsächlich prüfst — für einen Ein-Personen-Laden ist das der Unterschied zwischen einer Lizenz, die man sich nicht rechtfertigen kann, und ein paar Euro für einen tiefen Durchlauf. Diese Angabe stammt allerdings aus einer einzigen, undatierten Sekundärquelle. Und Slack hat am zwanzigsten August vier konkurrierende Coding-Agenten in eigene Kanäle geholt, mit Plan, Diff und Live-Vorschau in getrennten Reitern. Interessant ist nicht der Chat, sondern die Reiter: Wenn vier Rivalen in dieselbe Oberfläche zeichnen, geht die Wechselhürde gegen null.

Und noch eine erledigte Hausaufgabe: Continue ist tot. Acqui-Hire durch Cursor am sechzehnten Juni, letzte Fassung am neunzehnten Juni, Repository schreibgeschützt. Vorgestern stand das hier noch als unbelegte Behauptung. Morgen schauen wir, ob GitHub seine sechs Modelle am Montag wie angekündigt abschaltet, ob jemand die beiden SWE-Bench-Ranglisten in Einklang bringt, und ob der neue eingeschränkte Modus von Claude Code den Weg in fremde Firmen-Richtlinien findet.
