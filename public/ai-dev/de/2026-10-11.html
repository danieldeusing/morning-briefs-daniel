Sonntags-Test: Haiku 5.5 als Subagent-Modell

Aus der Woche. Zwei Bausteine passen zusammen. Erstens Claude Haiku 5.5 vom 07.10.: 0,10 $ pro Million Input-Tokens, 0,50 $ pro Million Output-Tokens, 1M Kontext.[1] Bei Prompts über 100K Tokens steigt der Preis auf 0,50 $ / 2,50 $.[2] Zweitens die Variable CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL aus Claude Code 2.1.296 vom 09.10. Sie lässt laut Changelog „every workflow agent on one model" laufen.[2]

Subagent: Ein Helfer-Agent, dem der Haupt-Agent eine Teilaufgabe gibt, etwa „durchsuche das Repo nach allen Aufrufen dieser Funktion". Wie ein Bauleiter, der einen Lehrling Material holen lässt. Der Lehrling muss nicht alles können, er muss nur schnell und billig sein. Genau dafür ist ein kleines Modell gedacht.

Zum Größenverhältnis: Sonnet 5.5 kostet 2 $ / 10 $, Opus 5.5 4 $ / 20 $.[1] Haiku 5.5 ist also 20-mal billiger als Sonnet. Für Coding hat Haiku 5.5 aber weiter keinen unabhängigen Benchmark-Wert. Die einzige bekannte Zahl misst Computer-Bedienung und kommt vom Hersteller.

Ausprobieren Setz die Variable für einen Workflow mit reiner Fleißarbeit (Dateien suchen, Logs zusammenfassen) auf claude-haiku-5-5. Vergleich das Ergebnis mit demselben Lauf auf Sonnet. Wenn Haiku dort mithält, sparst du beim größten Kostenblock. Wenn nicht, hast du ein paar Cent verloren.

Ein Vorbehalt: Die Variable gilt für alle Workflow-Agenten. Ein Workflow mit einem Planungsschritt läuft dann auch dort auf Haiku. Für gemischte Workflows passt die Variable deshalb nicht.

Claude Code wird zur Plattform

Aus der Woche, neu eingeordnet. Einzeln waren die Releases klein. Zusammen zeigen vier Versionen in zehn Tagen eine klare Richtung:

  • 2.1.287 (01.10.): „Claude Mods" lassen Plugins tiefer in das Verhalten eingreifen. Dazu kommt ein optionaler Agent „You Should Know".[1]
  • 2.1.292 (06.10.): Plugins direkt aus Marktplätzen installieren und steuern, wie stark Subagents arbeiten.[1]
  • 2.1.295 (08.10.): onFailure: "block" für Command- und HTTP-Hooks.[2]
  • 2.1.296 (09.10.): MCP-Tool-Beschreibungen und Server-Anweisungen dürfen jetzt 4.096 statt 2.048 Zeichen lang sein. Edit und NotebookEdit verweigern jetzt Änderungen an Dateien, die nicht UTF-8 sind, statt sie zu beschädigen.[2]
Hook mit „onFailure: block": Ein Hook ist ein eigenes Skript, das Claude Code vor oder nach einer Aktion ausführt, etwa ein Linter vor dem Speichern. Bisher konnte ein abgestürzter Hook einfach übergangen werden. Mit „block" gilt: Wenn die Prüfung selbst kaputt ist, geht es nicht weiter. Wie ein Rauchmelder, der die Tür verriegelt, wenn seine Batterie leer ist, statt still aufzugeben.

Die Angaben zu 2.1.287 und 2.1.292 stammen aus einem Release-Aggregator, nicht direkt aus dem GitHub-Changelog. Wir behandeln sie als Sekundärquelle.

Meine Sicht: Claude Code ist kein reines CLI-Tool mehr, sondern eine Laufzeit für fremde Erweiterungen. Das ist mächtig, aber jedes Plugin aus einem Marktplatz ist Code eines Fremden in deinem Terminal. Cursor geht mit Projects und Rollouts in dieselbe Richtung, aber zentral in der Cloud. Der UTF-8-Fix ist der unscheinbarste Punkt und für alte Codebasen mit Windows-1252 oder Shift-JIS der wichtigste.

Ausprobieren Wenn du einen Pflicht-Check als Hook hast (Tests, Secret-Scanner), stell ihn auf onFailure: "block". Ein Sicherheits-Check, der still ausfällt, ist schlimmer als keiner.

Lokal: mistral-large-4 bei Ollama

Ollama listet mistral-large-4, laut Bibliothek ein offenes multimodales Modell mit „52B active of 1.05T total parameters".[1] Die Seite zeigt nur „vor etwa 4 Tagen", kein genaues Datum.

Mixture of Experts (MoE): Das Modell besteht aus vielen Spezialisten. Pro Wort arbeiten nur wenige davon, hier 52 Mrd. Parameter. Wie eine Klinik mit hundert Fachärzten, von denen dich nur zwei untersuchen. Das macht jede Antwort schneller. Aber alle hundert brauchen trotzdem ein Büro, und das ist hier der Speicher für 1,05 Billionen Parameter.

Meine Sicht: Für den eigenen Rechner ist das nichts, auch nicht stark komprimiert. Lokal bleiben gemma4 und Qwen in der 27B-Klasse die praktische Wahl.

Die Codex CLI von OpenAI arbeitet an Version null Punkt einhundertdreiundsechzig. Die fünfte Alpha kam am Samstag, aber ohne Release-Notes. Stabil bleibt Version null Punkt einhundertzweiundsechzig Punkt eins vom Freitag.

Der Sonntags-Test: Claude Haiku fünf Komma fünf kostet zehn Cent pro Million Input-Tokens, zwanzigmal weniger als Sonnet. Claude Code wird Schritt für Schritt zur Plattform. In zehn Tagen kamen Claude Mods, Plugins direkt aus Marktplätzen, Hooks, die bei einem Fehler blockieren, und doppelt so lange MCP-Beschreibungen. Das ist mächtig, aber jedes Plugin ist fremder Code in deinem Terminal. Mein Tipp: Stell deine Pflicht-Prüfungen so ein, dass sie bei einem Fehler blockieren.

Zwei Fristen kommen. Am Mittwoch, dem vierzehnten Oktober, verschwindet GPT fünf Komma fünf aus ChatGPT und Codex, aber nicht aus der API. Am dreiundzwanzigsten Oktober schaltet Google einen alten Deep-Research-Agenten ab. Ein Blick in deine Konfigurationen nach fest eingetragenen Modellnamen dauert zehn Minuten.
