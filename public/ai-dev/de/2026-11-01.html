Claude Code: ein Effort-Regler nur für Subagenten

Gestern ging es um den Fast Mode. Dabei rutschte eine zweite Zeile aus 2.1.316 durch: „Added CLAUDE_CODE_SUBAGENT_EFFORT to set the effort level subagents run at“.[1] Du kannst also dem Hauptagenten viel Denkzeit geben und den Subagenten wenig, oder umgekehrt.

Effort-Level: Wie lange das Modell nachdenkt, bevor es antwortet. Mehr Effort heißt bessere Antworten bei schweren Aufgaben, aber mehr Token und mehr Wartezeit. Das ist wie die Wahl zwischen einem schnellen Blick und einer gründlichen Prüfung.

Meine Sicht: Das ist der nützlichste Schalter der Woche für alle, die viele Subagenten starten. Subagenten erledigen oft die mechanische Arbeit: Dateien suchen, Logs lesen, Tests laufen lassen. Dafür brauchen sie keine maximale Denkzeit. Wer das Effort für sie senkt, spart Token und Zeit, ohne den Hauptagenten dümmer zu machen. Umgekehrt gilt: Wenn deine Subagenten die eigentliche Recherche machen, setz den Wert nicht zu tief.

Ausprobieren Setz CLAUDE_CODE_SUBAGENT_EFFORT für eine Woche auf eine niedrigere Stufe und vergleiche Token-Verbrauch und Ergebnis. Warum: Es ist eine Zeile in der Umgebung, und du merkst schnell, ob die Qualität leidet.

Zur Erinnerung: Fast Mode für Opus 4.8

„Deprecated fast mode for Opus 4.8 as of October 30, 2026; it will be removed on November 30, 2026.“[1] Laut Changelog gibt es danach keinen automatischen Rückfall, Anfragen schlagen fehl. Der empfohlene Ersatz ist Opus 5.5. Noch 29 Tage.

API: größere Requests

Anthropic hat am 28.10. die maximale Request-Größe der Messages API und der Token Counting API von 32 MB auf 128 MB angehoben. Am 29.10. kam eine Usage and Cost Analytics API als Beta dazu.[2] Für dich heißt das: Große PDFs, viele Bilder oder lange Logs passen jetzt in einen einzigen Request. Das Kontextfenster des Modells bleibt aber die eigentliche Grenze.

Kimi K3.1 Pro: Mittwoch ist der Test

Moonshot bietet Kimi K3.1 Pro seit dem 23.10. nur über die API an, für 2 $ pro Million Input-Token und 10 $ pro Million Output-Token. Die Zusage lautet: „Full model weights will be released by Nov 4, 2026.“[1] Im Index von Artificial Analysis stand Kimi am 23.10. bei 55, Opus 5.5 bei 58.[1] Das war vor Carbon.

Open Weights: Der Hersteller gibt die trainierten Zahlen des Modells frei. Dann kannst du es selbst betreiben, auf eigener Hardware oder bei einem Anbieter deiner Wahl. Das ist wie ein Rezept statt eines Restaurantbesuchs.

Meine Sicht: Halten sie den Termin, hat die offene Welt ein Modell drei Index-Punkte hinter dem besten geschlossenen. Auf deinem Rechner läuft es trotzdem nicht. Ein Modell dieser Klasse braucht Server-Hardware. Für dich zählt es als günstige, austauschbare Alternative bei Hostern, nicht als Ollama-Modell. Prüf am Mittwoch zuerst die Lizenz, dann die Größe.

Terminal-Bench lesen: zwei Werte für ein Modell

Für Gemini 4 Carbon gibt es auf Terminal-Bench 4.0 zwei Zahlen. Vals misst 63,13 % (±2,20), Platz 4 von 59.[1] Ein Release-Tracker nennt 65,2 %.[2] Den Tracker konnten wir selbst nicht laden, die Zahl stammt aus einem Such-Snippet.

Der Unterschied ist wahrscheinlich kein Fehler. Benchmarks hängen am Harness, also an dem Programm, das das Modell durch die Aufgaben führt, und am Effort-Level. Andere Einstellungen geben andere Werte. Deshalb zitieren wir Vals: eine unabhängige Messung mit Fehlerspanne.

Terminal-Bench: Ein Test, bei dem ein Modell echte Aufgaben in einer Kommandozeile löst, etwa ein Projekt bauen oder einen Server einrichten. Gezählt wird, wie viele Aufgaben am Ende wirklich funktionieren. Das ist näher an deiner Arbeit mit Claude Code als ein reiner Code-Quiz-Test.

Bei GPT-6.1 Terra ist die Lage dünner. OpenAI meldet 50,3 % im höchsten Effort-Modus, gegen 21,5 % beim Vorgänger GPT-5.6 Terra.[3] Eine unabhängige Terminal-Bench-Messung für Terra haben wir nicht gefunden.

Meine Sicht: Zwei Prozentpunkte Abstand zwischen zwei Quellen sind so groß wie der Abstand zwischen Platz 1 und Platz 4. Ranglisten mit Nachkommastellen täuschen also Genauigkeit vor. Lies Terminal-Bench als Gruppen, nicht als Rangfolge. Carbon gehört zur Spitzengruppe. Terra liegt laut eigener Angabe eine Stufe darunter, kostet aber ein Viertel von Carbon. Einen SWE-bench-Verified-Wert gibt es für keins der neuen Modelle, deshalb heute keine Grafik.
