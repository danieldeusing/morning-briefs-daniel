Claude Code 2.1.317: drei kleine Sicherungen für Agenten

Das heutige Release ist kein Feature-Feuerwerk. Es schließt drei Lücken, die vor allem auffallen, wenn ein Agent unbeaufsichtigt läuft.[1]

1 · Rückfrage vor dem Versand deiner E-Mail-Adresse

Wörtlich: „Added a check that asks before a web or shell tool call sends your account email address to the network“.[1] Das Szenario dahinter: Eine Webseite oder eine Datei im Repo enthält versteckte Anweisungen, und der Agent baut deine Adresse in einen curl-Aufruf oder eine URL ein. Jetzt fragt Claude Code vorher nach.

Prompt Injection: Text, den der Agent beim Arbeiten liest (eine Webseite, ein README, ein Issue), und der wie eine Anweisung an ihn klingt. Das Modell kann nicht immer unterscheiden, ob du etwas willst oder ob nur ein fremder Text so tut. Das ist wie ein Zettel im Paket „Bitte schick die Rechnung an diese Adresse“, den der Lagerarbeiter einfach befolgt.

Meine Sicht: Gut, aber eng. Die Prüfung erkennt genau einen Wert, deine Account-Adresse. API-Keys, Kundendaten oder Code-Ausschnitte deckt sie nach dem Changelog-Text nicht ab. Für die bleiben Sandbox und Netzwerk-Regeln zuständig. Lies die Rückfrage als Rauchmelder: Wenn sie kommt, schau nach, welcher Text den Agenten dazu gebracht hat.

2 · Hooks, die bei einem Fehler blockieren

Für das Agent SDK gibt es onFailure: "block", „so a callback that fails blocks the action instead of letting it run“.[1] Bisher galt: Stürzt dein Prüf-Callback ab, läuft die Aktion trotzdem.

Fail-open vs. fail-closed: Was passiert, wenn der Wächter selbst ausfällt? Fail-open heißt: Tür bleibt offen. Fail-closed heißt: Tür bleibt zu. Ein Türsteher, der umkippt, sollte den Club nicht für alle öffnen.

Ausprobieren Wenn du mit dem SDK einen Hook als Sicherheitsprüfung nutzt (etwa „kein git push auf main“), setz onFailure: "block". Warum: Ein Wächter, der bei einem Timeout still durchwinkt, ist kein Wächter. Für reine Logging-Hooks lohnt es nicht, dort wäre ein Block nur lästig.

3 · claude -p meldet verlorene Schreibvorgänge

Bisher endete claude -p mit Exit-Code 0, auch wenn eine volle Platte oder ein Quota das Transkript oder ~/.claude.json verschluckt hatte. Jetzt gibt es eine Fehlermeldung und, bei Text- und JSON-Ausgabe, Exit-Code 1.[1] Für Cron-Jobs und CI heißt das: Ein Lauf, der still Daten verloren hat, fällt jetzt auf. Prüf, ob deine Skripte bei Exit 1 sauber abbrechen und nicht in einer Retry-Schleife landen.

Zur Erinnerung

  • Fast Mode für Opus 4.8: Ab dem 30.11. kommt ein Fehler zurück, „and do not fall back to standard Opus 4.8“. Ersatz ist Opus 5.5.[1] Noch 27 Tage.
  • Schreibschutz aus 2.1.314 (30.10.): permissions.blockWritesOutsideWorkingDirectories sperrt Write, Edit und NotebookEdit außerhalb deiner Arbeitsordner, in jedem Modus.[1] Den Schalter hatten wir gestern empfohlen.
  • Subagenten-Effort aus 2.1.316: CLAUDE_CODE_SUBAGENT_EFFORT legt fest, mit welchem Effort Subagenten laufen, wenn nichts anderes es vorgibt.[1]

Kimi K3.1 Pro: morgen ist der Termin

Moonshot bietet Kimi K3.1 Pro seit dem 23.10. über die API an, für 2 $ pro Million Input-Token und 10 $ pro Million Output-Token im Standard-Tarif. Die Gewichte sind „planned for release on November 4“.[1] Das ist morgen.

An der Lage von gestern hat sich nichts geändert. Lizenz und Benchmark-Werte nennt die Ankündigung nicht.[1] Terminal-Bench-Zahlen für Kimi kursieren, aber wir konnten keine davon an einer geladenen Quelle bestätigen. Deshalb nennen wir keine.

Meine Sicht: Für deinen Rechner ist das Modell zu groß. Interessant ist Kimi als offenes Modell, das Hoster günstig anbieten können. Achte morgen auf drei Dinge: die Lizenz, ob die offene Version dasselbe Modell ist wie das in der API, und wie schnell Drittanbieter es unter Moonshots Preis anbieten. Wir berichten am Donnerstag.

OpenAI: API-Guthaben für ChatGPT-Abonnenten

Im API-Changelog vom 28.10. steht: „Eligible ChatGPT Pro and Business subscribers can now claim up to $500 per month in free API credits.“[1] Wer die Bedingungen erfüllt, steht nicht in dem Eintrag. „Up to“ heißt außerdem: 500 $ ist die Obergrenze, nicht der Normalfall.

Meine Sicht: Das ist ein Köder für genau deine Zielgruppe. Wer ohnehin ein ChatGPT-Abo hat, kann GPT-6.1 Terra jetzt in einem eigenen Harness oder in Cline testen, ohne extra zu zahlen. Terra kostet laut OpenAI 1 $ pro Million Input- und 5 $ pro Million Output-Token.[2] Mit 500 $ kommst du damit weit. Den Terminal-Bench-4.0-Wert von 50,3 % bei maximalem Effort hat OpenAI selbst gemessen.[2] Eine unabhängige Messung fanden wir nicht.

Ausprobieren Wenn du Pro oder Business hast: Guthaben beantragen und Terra an zwei, drei echten Aufgaben aus deinem Repo gegen dein Standardmodell laufen lassen. Warum: Ein günstiges, schnelles Modell für Routine-Aufgaben spart Geld, und der Test kostet dich nichts.

Nicht für Coding, aber im selben Changelog: GPT-6 Rosalind (30.10.) ist ein Biologie-Modell nur für geprüfte Forscher.[1]

Benchmarks: heute nichts Neues, und das ist die Nachricht

Für keins der aktuellen Modelle fanden wir einen neuen, datierten Wert auf SWE-bench Verified, LiveCodeBench oder dem Aider-Leaderboard. Die Terminal-Bench-4.0-Werte, die zirkulieren, stammen weiter von den Herstellern: Opus 5.5 mit 66,4 % (Anthropic, xhigh)[1], Gemini 4 Carbon mit 65,2 % (Google, über einen Aggregator)[2], Terra mit 50,3 % (OpenAI). Deshalb heute keine Grafik.

Gemini 4 Carbon bleibt außerdem für dich unerreichbar. Seit dem 28.10. gibt es das Modell nur für Cyber-Verteidiger im Fairwind-Programm, und „there is no public API model or model card yet“.[2]

Es ist Dienstag, der dritte November. Von Sonntag bis heute kam kein neues Coding-Modell, weder bei Anthropic noch bei OpenAI, Google oder Cursor. Die einzige frische Bewegung ist ein kleines Release von Claude Code.

Version zwei Punkt eins Punkt dreihundertsiebzehn bringt drei Sicherungen. Erstens fragt Claude Code jetzt nach, bevor ein Web- oder Shell-Aufruf deine Account-E-Mail-Adresse ins Netz schickt. Das schützt vor Texten, die dem Agenten heimlich Anweisungen unterschieben. Die Prüfung erkennt aber nur diese eine Adresse, nicht etwa API-Schlüssel.

Für das Agent SDK gibt es einen Hook-Modus, der bei einem Fehler blockiert. Bisher lief eine Aktion weiter, wenn dein Prüf-Callback abstürzte. Wer Hooks als Sicherheitsprüfung nutzt, sollte diesen Modus einschalten. Außerdem endet der Kommandozeilen-Modus jetzt mit einem Fehlercode, wenn eine volle Platte das Transkript verschluckt hat. Für Cron-Jobs ist das eine gute Nachricht.

Zur Erinnerung: Der schnelle Modus für Opus vier Punkt acht fällt am dreißigsten November weg. Das sind noch siebenundzwanzig Tage.

Morgen will Moonshot die Gewichte von Kimi K drei Punkt eins Pro freigeben. Lizenz und Benchmark-Werte sind noch offen. Achte vor allem darauf, ob die offene Version dasselbe Modell ist wie das in der API.

OpenAI gibt Abonnenten von ChatGPT Pro und Business bis zu fünfhundert Dollar API-Guthaben im Monat. Damit lässt sich das günstige GPT-sechs Punkt eins Terra kostenlos an echten Aufgaben testen. Seine Benchmark-Werte stammen allerdings von OpenAI selbst.

Bei den Benchmarks gibt es heute keine neuen, unabhängigen Messungen. Und bei Cursor, Cline, OpenHands, Continue und Aider ist es still. Am Donnerstag schauen wir, was Kimi tatsächlich veröffentlicht hat.
