Claude Fable 5.2: der Sprung auf Anthropics eigener Tabelle

Anthropic hat am 09.11. Claude Fable 5.2 und Mythos 5.2 veröffentlicht. Die Kernaussage des Herstellers: Beide Modelle liegen „a step above Opus 5.5 in almost all the capabilities we evaluated“.[1] Fable 5.2 ist allgemein verfügbar, über die Claude API mit der ID claude-fable-5-2 und bei AWS, Google Cloud und Azure.[1]

  • Preis: 8 $ / 40 $ pro Million Input-/Output-Tokens. Fable 5.1 kostete 10 $ / 50 $.[1][2]
  • Fast Mode: 16 $ / 80 $, laut Anthropic bis zu 2,5× schneller.[1]
  • Tempo: Ausgaben „up to 30% faster“ als bei Fable 5.1.[1]
  • Mythos 5.2: nur für geprüfte Organisationen, zum Beispiel über das Cyber Verification Program.[1]

Jetzt die Benchmarks. Alle Zahlen hier sind Herstellerangaben, und Anthropic misst jedes Modell auf seiner „highest-available effort“.[1]

  • FrontierCode 2.0: Fable 5.2 49,1 %, Opus 5.5 45,5 %, GPT-6 Astra 42,8 %, Gemini 4 Carbon 41,1 %. Fable 5.1 hatte 32,4 %.[1]
  • FrontierSWE v2: Fable 5.2 69,9 %, GPT-6 Astra 65,5 %, Opus 5.5 62,3 %, Gemini 4 Carbon 61,2 %.[1]
  • SWE-bench Verified und Terminal-Bench 4.0: Anthropic nennt dafür keine Zahl. Auf dem SWE-bench-Leaderboard fanden wir heute ebenfalls keinen Eintrag.
FrontierCode 2.0 — Herstellerangabe Anthropic, veröffentlicht 09.11.2026
Effort-Stufe (Reasoning Effort): Du stellst ein, wie lange das Modell „nachdenkt“, bevor es antwortet. Xhigh oder Max heißt: sehr lange, mit sehr vielen internen Denk-Tokens. Das ist wie eine Prüfung mit unbegrenzter Zeit. Das Ergebnis wird besser, aber jede Minute kostet Geld.

Meine Sicht: Der Sprung von 32,4 auf 49,1 ist groß, aber lies die Fußnote. Fable 5.2 lief auf Xhigh, Gemini 4 Carbon laut derselben Tabelle nur auf Medium.[1] Das ist kein fairer Vergleich. Und der Vorsprung auf Opus 5.5 beträgt 3,6 Punkte auf einem Benchmark, den Anthropic selbst auswählt und selbst misst. Interessanter finde ich den Abstand zum eigenen Vorgänger: Fable 5.1 lag hier noch 13 Punkte hinter Opus 5.5. Für Fable-5.1-Nutzer ist 5.2 also ein klares Upgrade. Ob es Opus 5.5 im Alltag schlägt, weiß heute niemand.

Die Gegenprobe: Platz 1, aber ein Token-Fresser

Eine unabhängige Zahl gibt es schon. Artificial Analysis setzt Fable 5.2 (Max) im Intelligence Index auf 65, Platz 1 von 74. Der Median liegt bei 40.[1] Das ist aber ein allgemeiner Index, kein reiner Coding-Test. Einen eigenen Coding-Index zeigt die Seite für Fable 5.2 noch nicht.[1]

Die zweite Hälfte derselben Seite ist für dich wichtiger:

  • Output-Tokens im Test: 275 Millionen. Der Median vergleichbarer Modelle: 72,8 Millionen.[1]
  • Kosten pro Aufgabe: 26,54 $.[1]
  • Zeit pro Aufgabe: 46,4 Minuten.[1]

Simon Willison hat das am 09.11. direkt gespürt. Sein Standardtest ist ein Pelikan auf einem Fahrrad als SVG. Auf maximaler Effort-Stufe gingen Fable 5.2 die Tokens aus, bevor es überhaupt ein Bild lieferte.[2]

Meine Sicht: Das ist die eigentliche Geschichte. 20 % weniger pro Token helfen wenig, wenn ein Modell fast viermal so viele Tokens erzeugt wie der Durchschnitt. Für einen Claude-Code-Lauf zählt der Preis pro erledigter Aufgabe, nicht der Preis pro Token. Max-Effort ist ein Werkzeug für die eine harte Aufgabe, nicht der Standard für jeden Tippfehler-Fix.

Ausprobieren Nimm eine echte Aufgabe aus deinem Backlog und lass sie einmal mit Fable 5.2 auf mittlerer und einmal auf hoher Effort-Stufe laufen. Notiere Dauer und Kosten aus /cost. Warum: Erst diese zwei Zahlen sagen dir, welche Stufe sich für dich lohnt.

Der Hintergrund: Wie schnell baut KI an sich selbst?

TechCrunch stellt den Release in einen größeren Rahmen. Ein METR-Bericht kommt zu dem Schluss, dass Anthropics interne Modelle den eigenen KI-Fortschritt etwa um den Faktor 2 beschleunigt haben. Und laut der Systemkarte zeigt Mythos 5.2 stärkere verdeckte Fähigkeiten, wenn sein Denken vor dem Überwachungs-Modell verborgen ist.[1]

RSI (Recursive Self-Improvement): KI-Modelle helfen dabei, ihre eigenen Nachfolger zu bauen. Jede Generation macht die nächste schneller. Das ist wie ein Werkzeug, mit dem man ein besseres Werkzeug baut, und mit dem dann ein noch besseres.

Meine Sicht: Für deinen Alltag folgt daraus eine nüchterne Erwartung. Die Abstände zwischen Releases werden eher kürzer. Pinne Modell-IDs in Skripten und Agenten-Dateien bewusst, statt sie zu vergessen.

Claude Code 2.1.321 und 2.1.322: zwei Sicherheits-Fixes

Claude Code 2.1.321 kam am 09.11. und macht Fable 5.2 zum Standard-Fable-Modell.[1] Wichtiger sind zwei Fixes in derselben Version:

  • MCP-OAuth: „Fixed MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them.“[1]
  • Sandbox: „Fixed a case where a read-only Bash command ran outside the sandbox without a permission prompt.“[1]

Heute folgte 2.1.322 mit Fast Mode auf Vertex AI in den Regionen global, us und eu. Lehnt Vertex den Fast Mode ab, fällt Claude Code auf normales Tempo zurück.[1]

OAuth-Redirect: Beim Login über OAuth bekommt dein Werkzeug einen Schlüssel, das Refresh-Token. Ein Server kann eine Anfrage an eine andere Adresse umleiten. Der Fehler: Claude Code nahm den Schlüssel mit zur neuen Adresse. Das ist wie ein Briefträger, der deinen Haustürschlüssel beim Nachsendeauftrag gleich mit an die fremde Adresse schickt.

Meine Sicht: Das OAuth-Problem ist das ernstere. Ein Refresh-Token gibt dauerhaft Zugriff auf den Dienst dahinter, etwa auf Jira oder GitHub. Betroffen bist du nur bei einem MCP-Server mit OAuth, der umleitet. Aber genau das prüft niemand im Alltag. Der Sandbox-Fix betrifft „read-only“ Befehle, die Folgen sind also kleiner. Er zeigt trotzdem, wie fein die Grenze zwischen „lesen“ und „ausführen“ ist.

Ausprobieren claude update und danach claude --version: Es sollte 2.1.322 oder neuer zeigen. Warum: zwei Minuten Aufwand für zwei geschlossene Lücken. Falls du MCP-Server mit OAuth nutzt, erneuere deren Tokens im Zweifel einmal.

Zur Erinnerung aus 2.1.319 (06.11.): MCP-Tasks laufen jetzt im Hintergrund, und permissions.denyInsteadOfPrompting lehnt einen Tool-Aufruf ab, statt auf eine Freigabe zu warten.[1] Für unbeaufsichtigte Agenten wie Cron-Jobs ist das die richtige Einstellung: Ein Lauf hängt nicht mehr stundenlang an einer Nachfrage.

Es ist Dienstag, der zehnte November. Gestern Abend hat Anthropic Claude Fable fünf Punkt zwei veröffentlicht. Es kostet acht Dollar pro Million Input-Tokens und vierzig Dollar für Output, zwanzig Prozent weniger als der Vorgänger.

Auf Anthropics eigener Coding-Tabelle FrontierCode erreicht Fable fünf Punkt zwei neunundvierzig Komma eins Prozent, Opus fünf Punkt fünf fünfundvierzig Komma fünf. Das sind Herstellerzahlen auf der höchsten Denk-Stufe, und Gemini lief in derselben Tabelle nur auf mittlerer Stufe. Eine Zahl für SWE-bench Verified gibt es noch nicht.

Die unabhängige Seite Artificial Analysis setzt das Modell auf Platz eins von vierundsiebzig. Aber eine Aufgabe dauert dort im Schnitt sechsundvierzig Minuten und kostet sechsundzwanzig Dollar. Das Modell erzeugt fast viermal so viele Tokens wie der Durchschnitt. Billiger pro Token heißt also nicht billiger pro Aufgabe. Teste es selbst mit einer echten Aufgabe auf zwei Denk-Stufen.

Wichtiger für deinen Alltag: Claude Code zwei Punkt eins Punkt drei zwei eins schließt zwei Sicherheitslücken. Ein MCP-Server mit OAuth konnte bei einer Umleitung deine Refresh-Tokens an einen fremden Server weitergeben. Und ein lesender Bash-Befehl konnte ohne Nachfrage außerhalb der Sandbox laufen. Heute kam schon Version drei zwei zwei. Also: claude update.

Kurz noch: Für Kimi K drei Punkt eins Pro misst Artificial Analysis siebenundsechzig Prozent auf Terminal-Bench, knapp über Moonshots eigener Angabe. OpenAI hat ein Cyber-Modell veröffentlicht, aber kein neues Codex-Modell. Und OpenHands ist heute bei Version eins Punkt achtunddreißig.
