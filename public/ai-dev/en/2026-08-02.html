DeepSeek beats its own flagship

DeepSeek-V4-Flash-0731 moved from preview into public API beta on Jul 31, 2026. What's interesting isn't the move itself, but the table that comes with it on the model card: the model beats DeepSeek-V4-Pro (Preview) — the larger, pricier line from the same house — in all nine published agentic and coding benchmarks. Not by a little: on DeepSWE it's 54.4 versus 12.8, on Cybergym 76.7 versus 52.7, on DSBench-Hard 59.6 versus 31.1. Against its own predecessor, Terminal Bench 2.1 jumps from 61.8 to 82.7.

Agentic benchmark (Terminal Bench, DeepSWE): A classic coding test asks "write me this function" and compares the answer. An agentic benchmark instead drops the model into a real command line with a real project and says "make the tests pass" — the model has to find files, run commands, read errors, and fix things itself. The difference is the one between a written driving exam and the actual driving lesson: you can ace one and still clip the curb on the other. That's why these numbers say more about how a model performs inside a tool like Claude Code or Cursor than any HumanEval score — and why the jump from 61.8 to 82.7 on Terminal Bench is the line worth remembering.

What this costs — and what looks fishy about it

The price stays unchanged on the move out of preview: $0.14 per million input tokens, $0.28 per million output tokens, $0.0028 for cached input. A worked example with a made-up workload but real list prices: 10 million input and 2 million output tokens a month cost $1.96 with DeepSeek, $40 with Claude Sonnet 5 today, and $60 from September 1. That's not a quality judgment, just multiplication. But a factor of roughly 30 changes which tasks you even consider delegating at all: bulk refactors, log review, test generation across a whole repo slide from "too expensive to try" to "who cares, just run it."

On the required skepticism: the nine rows above are vendor figures on a vendor page. No independent board lists this model today. The only outside measurement findable comes from Artificial Analysis: Intelligence Index 50, "ranking #3 out of 101 models in its class," against a median of 25 in the same class. That backs the direction of the vendor table, but doesn't replace it. And there was a warning sign about secondary sources right alongside it: one widely cited article gives the predecessor's Terminal Bench value as 56.9, while the model card itself says 61.8. The lower number makes the jump bigger — exactly the kind of rounding error that never seems to go the other way.

artificialanalysis.ai/models/deepseek-v4-flash (independent, retrieved Aug 2, 2026) · xenospectrum.com and kingy.ai (Jul 31, 2026, price matches; no primary DeepSeek source for the price list was found here)
Cached input (prompt caching): Anyone who sends the same project context with every call pays to have it read every single time. With caching, the provider sets that preamble aside pre-processed — like a cook who chops the vegetables once in the morning instead of per order. Here it costs one-fiftieth of the normal input price: for agentic runs that push the same repo context through dozens of times, often the bigger lever than the output price.

And does it run locally? No. The weights are open, under MIT license on Hugging Face, but the model card lists 304 billion parameters total — plus an attached module for speculative decoding. That's server hardware, not a laptop. In 2026, "open weights" mostly means no vendor lock-in and a hosting provider of your choice — not automatically "runs at your desk" anymore. Anyone truly working locally stays in the 7-to-32-billion-parameter classes.

Claude Code: two defaults, pointing opposite ways

In July, Claude Code touched its permission-mode default twice — in opposite directions, something you'd barely notice in the version list. Since v2.1.200 (Jul 3), the interactive default mode is labeled "Manual" in the interface; the config value stays default, only the label got more honest. Since v2.1.207 (Jul 11), Auto mode is available by default on the managed providers — Amazon Bedrock, Google's Agent Platform, Microsoft Foundry, and signed-in Claude app sessions; the environment variable CLAUDE_CODE_ENABLE_AUTO_MODE=1, which used to be required, is gone.

Important for your gut sense of this: available doesn't mean active. The mode shows up in the switcher, but a session still starts in Manual unless defaultMode is set to auto. Organizations can disable it entirely via disableAutoMode in managed settings. There's also a model gate: on Bedrock, Agent Platform, Foundry, and the app gateway, only "Claude Sonnet 5, Opus 4.7 or later, and Fable 5" qualify per the documentation; via the Anthropic API and the Claude platform on AWS, it's Opus 4.6+, Sonnet 4.6+, or Fable 5.

code.claude.com/docs/en/permission-modes · official documentation, retrieved Aug 2, 2026
Permission mode: a coding agent wants to change files and run commands; the permission mode governs when it has to ask first. Manual is the intern who glances over before every step; Auto is the colleague who just gets going and shows you afterward what they did. Both are defensible — but only if you know which one is currently sitting at your keyboard. A default that behaves differently depending on the provider is exactly the kind of trap that catches people here.

Version status Current is v2.1.220 ("Bug fixes and reliability improvements"). The last substantively big entry remains v2.1.219, with Opus 5 as the new default Opus model and a 1M token context. Agent Teams remain experimental and gated behind CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 — the documentation is unambiguous there: "Agent teams are experimental and disabled by default." Anyone testing them should be on at least v2.1.207: before that, a single malformed mailbox entry could trigger a second-by-second loop of error messages that could only be stopped by deleting the file.

Cursor 3.11 — a three-week-old catch-up

While retracing the changelog, an entry surfaced that never made it into this space and is the most relevant one of the month for anyone building their own harness. Cursor 3.11, from Jul 10, 2026, brought three things: side chats (/side, /btw, or the plus button) for follow-up questions, "without interrupting" the running agent work; conversation search across all agent transcripts via Cmd+K, with a local index for thousands of conversations; and cloud agent hooks that, per the changelog, "observe and control the agent conversation itself: prompts, responses, thinking, subagents, compaction, and turn completion" — hook points into the agent dialogue itself, explicitly meant for output monitoring and self-correcting loops.

The third point is the real one: hooks on prompt, response, thinking step, sub-agent, and compaction are exactly the places where you hang your own quality control on someone else's agent without forking it. Worth trying Why try it: one file, .cursor/hooks.json, is enough to log what the agent actually does — before you hand it more permissions. Since then, the only newer things from Cursor are the iPad client (Jul 29), Cursor Start (Jul 28), and Router (Jul 22); nothing in the last seven days.
