The silent switch: both CLIs now use a cheaper default model

On Wednesday, Oct 7, the same thing happened twice. Claude Code 2.1.293 "now defaults to the faster, more affordable Claude Haiku 5.5 model with 1M context window".[1] And the Codex CLI 0.161.0 "now defaults to the faster GPT-6.1 Sol model".[2] Both statements come from a release tracker, not directly from the changelogs. We treat them as a secondary source.

Prices compared, each per million tokens (input / output):

ModelPriceSource
Claude Haiku 5.5$0.10 / $0.50 (up to 100K tokens; above that $0.50 / $2.50)Blog, secondary[3]
GPT-6.1 Sol$2 / $10Trade press, secondary[4]
Claude Opus 5.5$4 / $20Anthropic[5]

The two new defaults play in different leagues. Haiku 5.5 is a small model and costs one twentieth of Sol. OpenAI describes Sol as "near-Astra performance for complex work at a lower cost than Astra", so close to flagship level.[6] Anthropic makes the default cheap; OpenAI makes it nearly as good as the top model.

Tokenizer: The model does not read text in letters but in pieces called tokens. The tokenizer cuts the text into these pieces. According to Simon Willison, Haiku 5.5 has a new, "less generous" tokenizer: the same text yields about 1.25 times as many tokens as with Haiku 4.5.[3] Like a taxi with the same price per kilometer that suddenly counts in miles instead. The list price stays, the bill goes up.

My take: the Haiku switch is the tricky part. There is no independent coding benchmark for Haiku 5.5. If Claude Code suddenly seems weaker in a hard refactoring, the model may be the cause, not you. With Codex the risk is smaller: Sol more likely replaces an older model with a better one.

Try it Type /model in Claude Code and see what is active. For hard tasks, pin the model deliberately. For grunt work, let Haiku run and compare one run against Sonnet. That way you learn where the cheap model is enough.

GPT-6.1 Sol: Ultrafast and cost per task

Since Oct 8, "Ultrafast" has been available for GPT-6.1 Sol in Codex and ChatGPT Work. According to the OpenAI changelog, the mode is only available on "Pro $500 and eligible Enterprise and Edu plans".[1] On Enterprise it is off by default. At DevDay, OpenAI cited for Ultrafast (first on Astra), per the trade press, "up to eight times faster token generation, at 300 tokens per second".[2]

The more interesting number is a different one. OpenAI gives Sol a cost of $5.47 per task, against $23.21 for Opus 5.5 (Terminal-Bench Science 0.1, max reasoning effort; Astra: $23.80). On DeepSWE v1.1, Sol is said to match GPT-6 Astra at about one fifth of the cost.[2] These are exclusively OpenAI's own figures. We found no independent check.

My take: "cost per solved task" is the right metric for agents, better than price per token. A cheap model that starts over three times ends up expensive. I would still not believe the number until someone else re-measures it. Ultrafast at $500 a month is not an option for solo developers.

Deadline Wednesday: GPT-5.5 disappears from Codex

According to the OpenAI changelog: "On October 14, 2026, GPT-5.5 will retire from ChatGPT, ChatGPT Work, and Codex on all plans". And: "This retirement does not apply to the OpenAI API."[1]

My take: if you still have GPT-5.5 hard-coded in Codex or in scripts, switch by Wednesday. Search configs and CI variables for the model name. It takes ten minutes. Then test a typical prompt on the successor, because new models often react differently to old prompts.

Benchmark picture: everyone wins their own table

Put the announcements of the last three weeks side by side and a pattern shows. All numbers in this paragraph come from the vendors themselves:

  • Anthropic (Sep 22): Opus 5.5 leads Terminal-Bench 4.0 with 66.4%, ahead of GPT-6 Astra with 57.9%.[1]
  • OpenAI (Sep 29): Sol matches Astra on DeepSWE v1.1. On Terminal-Bench-Science 0.1, Astra leads with 68.1%.[2]
  • Google (Sep 30): Gemini 4 Argon leads DeepSWE v1.1 with 77.9%, ahead of Opus 5.5 with 74.2%. On Terminal-Bench 4.0, however, Argon trails with 57.4%.[3]
  • DeepSeek (Sep 10): V4.1-Flash reaches 74.2 on DeepSWE v1.1, just ahead of Opus 5 with 74.0.[4]

One detail shows the problem: for Astra on Terminal-Bench-Science, Anthropic reports 64.6%, OpenAI 68.1%.[1][2] Same model, same test, a 3.5-point difference. Presumably this comes from a different test environment or a different date. We know the Argon numbers only from search results, not from the Google page. According to these sources, Bloomberg reports that Argon is weaker on real coding work. Google disputes this.[3]

Why vendor benchmarks prove little: Every vendor picks the tests, the settings and the timing. Like a restaurant that writes its own reviews. It does not have to lie to do so. Showing only the dishes that turned out well is enough. Add contamination: if test tasks were in the training material, the test measures memory instead of skill.

Two sources are independent. In Code Arena WebDev, people vote blind on which result is better. As of Oct 8:[5]

Code Arena WebDev — Top 5, as of 2026-10-08 (Elo score)

The Artificial Analysis Intelligence Index sees it similarly: Opus 5.5 ahead with 58, Sonnet 5.5 with 56, then Fable 5.1, GPT-6 Astra and Gemini 4 Argon with 53 each.[6] The page carries no date. But it lists Opus 5.5, so it is no older than Sep 22.

SWE-Bench Verified is missing entirely this week. The page loads its table via JavaScript, and we got no values. We do not use older numbers from blogs.

My take: the independent sources agree that Anthropic is ahead right now. In the Arena, though, it is only 27 points between first and second place. That is a narrow gap. For your daily work, what matters more is which model your harness uses as its default, see above.

Open weights: DeepSeek V4.1-Flash and Mistral Large 4

DeepSeek V4.1-Flash was released on Sep 10 under the MIT license, with 1M context.[1] Reports on its size conflict. TNW and Simon Willison say 552B parameters, another source 763B. We use 552B. On DeepSWE v1.1 DeepSeek reports 74.2, but on ProgramBench only 20.3, against 37.0 for the comparison model in the article.[1] The old V4-Pro is shut down, and requests have landed on V4.1-Flash since Sep 14.[1]

Mistral Large 4 has been available as a preview via API since Oct 6: "a 1 trillion parameter, 49 billion active parameter model".[2] In the Artificial Analysis index it scores 38, its predecessor Large 3 scores 9. Open weights are promised for "end of this month". License and price are still open.[2]

Active parameters: Large open models today consist of many specialists (Mixture of Experts). Per word, only a few of them work, for Mistral 49B out of 1 trillion. That makes the answer fast. But all of them must sit in memory. For Ollama on a laptop, both models are therefore too big.

My take: DeepSeek is exciting, but not as a laptop model. It is exciting as a cheap API or on a rented GPU when code must not leave the house. The ProgramBench gap shows that on tasks that demand a whole program, it clearly lags behind. For local work, models of the 27B class remain the practical choice.

Harness comparison: agents leave the laptop

Three tools moved in the same direction last week. Cursor (Oct 6): "You can now see and reply to the local agents running on your computer from the Cursor iOS app."[1] Since Sep 23 it has Security Review, which "reads every pull request in the context of the codebase".[1] Codex has run locally, from the phone or in the cloud since DevDay.[2] GitHub Copilot in VS Code got "Automations" in the September release, meaning scheduled agent tasks, as a preview.[3] According to Simon Willison, Anthropic's Cowork now also runs model and VM in the cloud.[4]

My take: the agent becomes a background service that you nudge from your phone. That is convenient. But it also means an agent keeps working while you are not looking. Permissions and hooks become more important than the choice of model.

Try it If you use Cursor: start a long agent run locally and reply via the iOS app. That shows whether remote control helps your workflow or only distracts.

It's Monday, October twelfth, and it's a quiet one. Since Friday there's been no new model and no new stable release of Claude Code or Codex. So we're taking stock of the past week.

On Wednesday, October fourteenth, GPT five point five goes away from ChatGPT and Codex. The API isn't affected. Before then, search your configs for the model name.
