Claude Code: an effort dial just for subagents

Yesterday was about fast mode. A second line from 2.1.316 slipped through: “Added CLAUDE_CODE_SUBAGENT_EFFORT to set the effort level subagents run at”.[1] So you can give the main agent a lot of thinking time and the subagents little, or the other way around.

Effort level: How long the model thinks before it answers. More effort means better answers on hard tasks, but more tokens and more waiting. It is like choosing between a quick glance and a thorough check.

My take: this is the most useful switch of the week for anyone who launches many subagents. Subagents often do the mechanical work: searching files, reading logs, running tests. They do not need maximum thinking time for that. Lowering the effort for them saves tokens and time without making the main agent dumber. The reverse also holds: if your subagents do the actual research, do not set the value too low.

Try it Set CLAUDE_CODE_SUBAGENT_EFFORT to a lower level for a week and compare token use and results. Why: it is one line in the environment, and you will quickly see whether quality suffers.

Reminder: fast mode for Opus 4.8

“Deprecated fast mode for Opus 4.8 as of October 30, 2026; it will be removed on November 30, 2026.”[1] According to the changelog there is no automatic fallback afterwards; requests fail. The recommended replacement is Opus 5.5. 29 days left.

API: larger requests

On Oct 28, Anthropic raised the maximum request size of the Messages API and the Token Counting API from 32 MB to 128 MB. On Oct 29, a Usage and Cost Analytics API followed as a beta.[2] For you, that means large PDFs, many images or long logs now fit into a single request. The model's context window remains the real limit, though.

Kimi K3.1 Pro: Wednesday is the test

Moonshot has offered Kimi K3.1 Pro through the API only since Oct 23, for $2 per million input tokens and $10 per million output tokens. The pledge reads: “Full model weights will be released by Nov 4, 2026.”[1] In the Artificial Analysis index, Kimi stood at 55 on Oct 23, Opus 5.5 at 58.[1] That was before Carbon.

Open weights: The vendor releases the model's trained numbers. Then you can run it yourself, on your own hardware or with a provider of your choice. It is like getting the recipe instead of eating at the restaurant.

My take: if they hold the date, the open world gets a model three index points behind the best closed one. It still will not run on your machine. A model of this class needs server hardware. For you, it counts as a cheap, swappable alternative at hosting providers, not as an Ollama model. On Wednesday, check the license first, then the size.

Reading Terminal-Bench: two scores for one model

Gemini 4 Carbon has two numbers on Terminal-Bench 4.0. Vals measures 63.13% (±2.20), rank 4 of 59.[1] A release tracker lists 65.2%.[2] We could not load the tracker ourselves; the number comes from a search snippet.

The difference is probably not an error. Benchmarks depend on the harness, meaning the program that guides the model through the tasks, and on the effort level. Different settings give different values. That is why we cite Vals: an independent measurement with a margin of error.

Terminal-Bench: A test in which a model solves real tasks on a command line, such as building a project or setting up a server. What counts is how many tasks really work in the end. That is closer to your work with Claude Code than a pure code quiz.

For GPT-6.1 Terra the picture is thinner. OpenAI reports 50.3% in the highest effort mode, against 21.5% for the predecessor GPT-5.6 Terra.[3] We found no independent Terminal-Bench measurement for Terra.

For Carbon, Artificial Analysis lists an API price. Whether developers without clearance from Google's cyber program really get access, we could not confirm today. Yesterday the access was still considered restricted.

My take: a two-percentage-point gap between two sources is as large as the gap between rank 1 and rank 4. Rankings with decimal places therefore fake precision. Read Terminal-Bench as groups, not as a ranking. Carbon belongs to the top group. By its own claim, Terra sits one tier below, but costs a quarter of Carbon.
