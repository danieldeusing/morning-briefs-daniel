Claude Code 2.1.317: three small safeguards for agents

Today's release is no feature fireworks. It closes three gaps that mostly show up when an agent runs unattended.[1]

1 · Confirmation before your email address is sent

Verbatim: "Added a check that asks before a web or shell tool call sends your account email address to the network".[1] The scenario behind it: a web page or a file in the repo contains hidden instructions, and the agent builds your address into a curl call or a URL. Now Claude Code asks first.

Prompt injection: Text the agent reads while working (a web page, a README, an issue) that sounds like an instruction to it. The model cannot always tell whether you want something or whether foreign text is just pretending. It is like a note in a package, "Please send the invoice to this address," that the warehouse worker simply follows.

My take: good, but narrow. The check detects exactly one value, your account address. Going by the changelog text, it does not cover API keys, customer data or code snippets. Sandbox and network rules stay responsible for those. Read the prompt as a smoke detector: when it fires, look at which text pushed the agent to do it.

2 · Hooks that block on failure

The Agent SDK gets onFailure: "block", "so a callback that fails blocks the action instead of letting it run".[1] Until now, if your check callback crashed, the action ran anyway.

Fail-open vs. fail-closed: What happens when the guard itself goes down? Fail-open means the door stays open. Fail-closed means the door stays shut. A bouncer who faints should not open the club to everyone.

Try it If you use a hook as a safety check in the SDK (say, "no git push to main"), set onFailure: "block". Why: a guard that silently waves things through on a timeout is no guard. For pure logging hooks it is not worth it; a block there would just be annoying.

3 · claude -p reports lost writes

Until now, claude -p exited with code 0 even when a full disk or a quota had swallowed the transcript or ~/.claude.json. Now there is an error message and, for text and JSON output, exit code 1.[1] For cron jobs and CI, that means a run that silently lost data now stands out. Check that your scripts abort cleanly on exit 1 and do not end up in a retry loop.

As a reminder

  • Fast Mode for Opus 4.8: from Nov 30 you get an error, "and do not fall back to standard Opus 4.8". The replacement is Opus 5.5.[1] 27 days left.
  • Write protection from 2.1.314 (Oct 30): permissions.blockWritesOutsideWorkingDirectories blocks Write, Edit and NotebookEdit outside your working folders, in every mode.[1] We recommended that switch yesterday.
  • Subagent effort from 2.1.316: CLAUDE_CODE_SUBAGENT_EFFORT sets the effort subagents run at when nothing else specifies it.[1]

Kimi K3.1 Pro: the date is tomorrow

Moonshot has offered Kimi K3.1 Pro through the API since Oct 23, at $2 per million input tokens and $10 per million output tokens on the standard tier. The weights are "planned for release on November 4".[1] That is tomorrow.

Nothing has changed since yesterday's picture. The announcement names neither a license nor benchmark values.[1] Terminal-Bench numbers for Kimi are circulating, but we could not confirm any of them against a loaded source. So we cite none.

My take: the model is too big for your machine. Kimi is interesting as an open model that hosters can offer cheaply. Watch three things tomorrow: the license, whether the open version is the same model as the one in the API, and how fast third parties offer it below Moonshot's price. We report on Thursday.

OpenAI: API credit for ChatGPT subscribers

The Oct 28 API changelog says: "Eligible ChatGPT Pro and Business subscribers can now claim up to $500 per month in free API credits."[1] The entry does not say who meets the conditions. "Up to" also means $500 is the ceiling, not the normal case.

My take: this is bait for exactly your audience. If you already have a ChatGPT plan, you can now test GPT-6.1 Terra in your own harness or in Cline without paying extra. According to OpenAI, Terra costs $1 per million input tokens and $5 per million output tokens.[2] $500 goes a long way at that price. OpenAI measured the Terminal-Bench 4.0 score of 50.3% at maximum effort itself.[2] We found no independent measurement.

Try it If you have Pro or Business: claim the credit and run Terra against your default model on two or three real tasks from your repo. Why: a cheap, fast model for routine tasks saves money, and the test costs you nothing.

Not for coding, but in the same changelog: GPT-6 Rosalind (Oct 30) is a biology model for vetted researchers only.[1]

Benchmarks: nothing new today, and that is the news

For none of the current models did we find a new, dated value on SWE-bench Verified, LiveCodeBench or the Aider leaderboard. The Terminal-Bench 4.0 values in circulation still come from the vendors: Opus 5.5 at 66.4% (Anthropic, xhigh)[1], Gemini 4 Carbon at 65.2% (Google, via an aggregator)[2], Terra at 50.3% (OpenAI). That is why there is no chart today.

Gemini 4 Carbon also remains out of reach for you. Since Oct 28 the model has been available only to cyber defenders in the Fairwind program, and "there is no public API model or model card yet".[2]

It's Tuesday, November third. From Sunday through today, no new coding model has shipped, not from Anthropic, OpenAI, Google or Cursor. The only fresh movement is a small Claude Code release.

Version two point one point three seventeen brings three safeguards. First, Claude Code now asks before a web or shell call sends your account email address out to the network. That protects against text that quietly slips instructions to the agent. But the check only recognizes that one address, not, say, API keys.

The Agent SDK gets a hook mode that blocks on failure. Until now, if your check callback crashed, the action kept going. If you use hooks as a safety check, you should switch this mode on. Also, command-line mode now exits with an error code when a full disk swallows the transcript. For cron jobs, that's good news.

A reminder: fast mode for Opus four point eight goes away on November thirtieth. That's twenty-seven days from now.

Tomorrow, Moonshot plans to release the weights of Kimi K three point one Pro. The license and benchmark numbers are still open. Above all, watch whether the open version is the same model as the one in the API.

OpenAI is giving ChatGPT Pro and Business subscribers up to five hundred dollars a month in API credit. That lets you test the cheap GPT-six point one Terra on real tasks for free. Its benchmark numbers, though, come from OpenAI itself.
