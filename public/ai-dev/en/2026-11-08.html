The week in one sentence: agents without supervision

Look at this week's changelogs, and almost every change answers the same question: What does the agent do when nobody is watching?

  • Claude Code shipped three releases in five days. In 2.1.319, MCP tasks run “in the background by default”.[1] The new setting permissions.denyInsteadOfPrompting “denies tool calls that would wait on a prompt”.[1] The date varies by a day: havoptic gives Nov 6, releasebot gives Nov 7.[1][2]
  • Agent SDK: Since 2.1.317 there is onFailure: "block" for hook callbacks.[2] A hook that crashes then blocks the action instead of letting it through.
  • Codex CLI 0.167.0 (Nov 6) has a command center for agents, started with codex agents --no-daemon. It flags unread results.[3]
  • OpenAI Agents API (Oct 30): Sessions can change tools mid-run and compact the context in the background by default.[4]
  • Cursor: Cloud agents build a web app with a database and login and put it online under a shareable link (Nov 5).[5]
Hook: A small script the agent calls before or after an action, for example a linter before every commit. It works like a bouncer. The question so far was: What happens if the bouncer passes out? With "block" the door stays shut.

My take: This is the right direction, and it has a price. It used to be that an agent run was safe because you sat next to it and clicked “Yes”. Now the safety lives in a JSON file. That is better for automation, but you only notice a wrong line of configuration in the log. My advice for this week: after every unattended run, read the log of denied actions. That list shows you which rules are missing or too strict.

Try it permissions.blockWritesOutsideWorkingDirectories in Claude Code. According to the changelog, the setting blocks Write, Edit and NotebookEdit outside the working folders, “in every permission mode”.[2] Why: An agent that runs alone overnight should not be able to write into ~/.ssh or into another repo. That is one line of configuration for a real risk.

Deadline Nov 30: Fast mode for Opus 4.8 goes away

According to Anthropic, fast mode for Opus 4.8 is deprecated “and will be removed on November 30, 2026”. Anthropic recommends switching to Opus 5.5.[1] As of today that leaves 22 days.

What you should check beforehand:

  • Scripts and agent configurations that hard-code Opus 4.8 with fast mode.
  • Subagent definitions with a fixed model ID instead of an alias.
  • Cost: A different model needs a different number of rounds for the same task. Measure a real run before you delete the old configuration.

My take: This is boring news, but it can quietly break your cron jobs from Dec 1. Run grep once now for the model ID in your agent files. It takes two minutes.

Haiku 5.5: cheap, but not for everything

Haiku 5.5 came out as early as Oct 7. It still matters this week: When more and more subagents run in the background, the price per run counts. Haiku 5.5 costs $0.10 input and $0.50 output per million tokens, up to 100,000 tokens of context.[1]

The figures are vendor claims, and we found no independent measurement:

  • Terminal-Bench 4.0: Haiku 5.5 scores 39.2%, Sonnet 5.5 scores 70.6%.[1]
  • FrontierCode 1.1: Haiku 5.5 scores 46.4%.[1]
  • Anthropic gives no SWE-bench figure.
Subagent: A second, smaller agent that the main agent starts for a subtask, for example “find all places that call this function”. It is like an apprentice who fetches the tool while the master does the work.

My take: Anthropic itself says Sonnet and Opus 5.5 “remain better choices” for complex agentic coding tasks.[1] That is honest, and it fits the gap on Terminal-Bench. Use Haiku for searching, summarizing and reading logs. Do not use it for changes to code. A cheap subagent that edits the wrong file ends up costing you more than an expensive one.

OpenAI: Codex as an alpha on Saturday, a security model on Thursday

The stable Codex CLI is still 0.167.0 from Nov 6. On Saturday, 0.169.0-alpha.3 arrived as a pre-release.[1] We did not review the alpha's notes. For daily work, stay on the stable version.

The API changelog had no separate Codex entry in October and November. The new models are GPT-6.1 Terra (Oct 26) and GPT-6-Cyber (Nov 5).[2] GPT-6-Cyber is built for security work: “finding vulnerabilities, reproducing them in authorized test environments, and verifying fixes”.[2]

My take: GPT-6-Cyber belongs more in the software and security area than here. The “verifying fixes” part is interesting for developers, though. A model that checks whether your patch really closes the hole is a good counterweight to a coding agent that wrote the patch. The security side belongs in the Software brief.

Local: Qwen3.8 27B for your Sunday

Qwen3.8 is on Ollama in the 27B size with 18 GB and 256K context. It processes text and images.[1] When the model was last updated is unclear: The page says “5 hours ago”, the tag list says “1 month ago”. On Nov 3, Simon Willison showed that Qwen 3.8 27B can even read and interpret the weights of a neural network on his laptop.[2]

Context window (256K): The amount of text the model can hold “in its head” at once, here about 256,000 tokens. It is like a desk: The bigger it is, the more files lie open at the same time. But a full desk also needs more working memory.

Also new in the Ollama library are kimi-k3.1-pro (3 days ago) and mimo-v2.6 (4 days ago), as of Nov 8.[3] We did not check whether Kimi K3.1 Pro runs there as a local model or only as a cloud variant. With 2.8 trillion parameters, it would not fit on any laptop anyway.

Try it ollama pull qwen3.8:27b. Why: 18 GB fits on a machine with 32 GB of memory, and for code explanations or commit messages you do not need a cloud agent.

It's Sunday, November eighth, and it's a quiet one. Since yesterday, the only thing to land is a pre-release of Codex CLI. So today we're looking back at the week.

The theme of the week: agents without supervision. Claude Code shipped three versions in five days. Long MCP calls now run in the background, and a new setting turns down actions instead of waiting for a prompt. Codex CLI got a command center for agents, and at Cursor, cloud agents now put whole web apps online. That means safety no longer lives in your click, it lives in your configuration. So after every unattended run, read the list of denied actions.

One concrete tip: Claude Code has a setting that blocks writes outside the working folder, in every mode. For overnight runs, that's one line of configuration against a real risk.

A deadline: On November thirtieth, fast mode for Opus four point eight goes away. Anthropic recommends Opus five point five. That leaves twenty-two days. Search your scripts and agent files now for the old model ID.

If you want to run subagents cheaply, look at Haiku five point five. It costs ten cents per million input tokens. But according to Anthropic, it only scores thirty-nine point two percent on Terminal-Bench, while Sonnet five point five scores seventy point six. Use Haiku for searching and summarizing, not for changing code.

Over at OpenAI, GPT-6-Cyber is new, a model for security work that finds vulnerabilities and checks patches. For your laptop, Qwen three point eight in the twenty-seven B size is a good candidate: eighteen gigabytes, two hundred fifty-six thousand tokens of context, available through Ollama.

There are no new benchmark numbers today, so no chart either. Among the open-source agents, OpenHands was the busiest, with three releases in four days. Cline, Continue and Aider stay quiet. Next week we'll see whether anyone measures the new models independently on SWE-bench.
