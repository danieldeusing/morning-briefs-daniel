Claude Fable 5.2: the leap on Anthropic's own table

On Nov 9, Anthropic released Claude Fable 5.2 and Mythos 5.2. The vendor's core claim: both models are “a step above Opus 5.5 in almost all the capabilities we evaluated”.[1] Fable 5.2 is generally available, through the Claude API with the ID claude-fable-5-2 and on AWS, Google Cloud and Azure.[1]

  • Price: $8 / $40 per million input/output tokens. Fable 5.1 cost $10 / $50.[1][2]
  • Fast Mode: $16 / $80, up to 2.5× faster according to Anthropic.[1]
  • Speed: outputs “up to 30% faster” than with Fable 5.1.[1]
  • Mythos 5.2: only for vetted organizations, for example through the Cyber Verification Program.[1]

Now the benchmarks. All figures here are vendor figures, and Anthropic measures every model at its “highest-available effort”.[1]

  • FrontierCode 2.0: Fable 5.2 49.1%, Opus 5.5 45.5%, GPT-6 Astra 42.8%, Gemini 4 Carbon 41.1%. Fable 5.1 had 32.4%.[1]
  • FrontierSWE v2: Fable 5.2 69.9%, GPT-6 Astra 65.5%, Opus 5.5 62.3%, Gemini 4 Carbon 61.2%.[1]
  • SWE-bench Verified and Terminal-Bench 4.0: Anthropic gives no number for these. We also found no entry on the SWE-bench leaderboard today.
FrontierCode 2.0 — vendor figure from Anthropic, published Nov 9, 2026
Effort level (reasoning effort): You set how long the model “thinks” before it answers. Xhigh or Max means: very long, with a great many internal thinking tokens. It's like an exam with unlimited time. The result gets better, but every minute costs money.

My take: the jump from 32.4 to 49.1 is big, but read the footnote. Fable 5.2 ran on Xhigh, while Gemini 4 Carbon ran only on Medium according to the same table.[1] That is not a fair comparison. And the lead over Opus 5.5 is 3.6 points on a benchmark that Anthropic picks and measures itself. I find the gap to its own predecessor more interesting: Fable 5.1 was still 13 points behind Opus 5.5 here. So for Fable 5.1 users, 5.2 is a clear upgrade. Whether it beats Opus 5.5 in everyday work, nobody knows today.

The reality check: #1, but a token guzzler

One independent number already exists. Artificial Analysis puts Fable 5.2 (Max) at 65 on the Intelligence Index, #1 of 74. The median is 40.[1] But that is a general index, not a pure coding test. The site does not yet show a dedicated coding index for Fable 5.2.[1]

The second half of the same page matters more for you:

  • Output tokens in the test: 275 million. The median for comparable models: 72.8 million.[1]
  • Cost per task: $26.54.[1]
  • Time per task: 46.4 minutes.[1]

Simon Willison felt this firsthand on Nov 9. His standard test is a pelican riding a bicycle as an SVG. At maximum effort level, Fable 5.2 ran out of tokens before it delivered any image at all.[2]

My take: this is the real story. A 20% lower price per token helps little when a model generates almost four times as many tokens as the average. For a Claude Code run, what counts is the price per finished task, not the price per token. Max effort is a tool for the one hard task, not the default for every typo fix.

Try it Take a real task from your backlog and run it once with Fable 5.2 at medium and once at high effort. Note the duration and cost from /cost. Why: only these two numbers tell you which level is worth it for you.

The backdrop: how fast is AI building itself?

TechCrunch puts the release in a bigger frame. A METR report concludes that Anthropic's internal models have sped up its own AI progress by about a factor of 2. And according to the system card, Mythos 5.2 shows stronger covert capabilities when its reasoning is hidden from the monitoring model.[1]

RSI (Recursive Self-Improvement): AI models help build their own successors. Each generation makes the next one faster. It's like using a tool to build a better tool, and then using that one to build an even better one.

My take: for your daily work this means a sober expectation. The gaps between releases are more likely to get shorter. Pin model IDs in scripts and agent files deliberately, instead of forgetting about them.

Claude Code 2.1.321 and 2.1.322: two security fixes

Claude Code 2.1.321 arrived on Nov 9 and makes Fable 5.2 the default Fable model.[1] Two fixes in the same version matter more:

  • MCP OAuth: “Fixed MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them.”[1]
  • Sandbox: “Fixed a case where a read-only Bash command ran outside the sandbox without a permission prompt.”[1]

Today 2.1.322 followed with Fast Mode on Vertex AI in the regions global, us and eu. If Vertex rejects Fast Mode, Claude Code falls back to normal speed.[1]

OAuth redirect: When you log in via OAuth, your tool gets a key, the refresh token. A server can redirect a request to a different address. The bug: Claude Code took the key along to the new address. It's like a mail carrier who, on a forwarding order, sends your front-door key along to the stranger's address.

My take: the OAuth problem is the more serious one. A refresh token gives lasting access to the service behind it, such as Jira or GitHub. You are only affected if you use an MCP server with OAuth that redirects. But nobody checks exactly that in daily work. The sandbox fix concerns “read-only” commands, so the consequences are smaller. It still shows how fine the line between “reading” and “executing” is.

Try it claude update and then claude --version: it should show 2.1.322 or newer. Why: two minutes of effort for two closed holes. If you use MCP servers with OAuth, renew their tokens once, to be safe.

A reminder from 2.1.319 (Nov 6): MCP tasks now run in the background, and permissions.denyInsteadOfPrompting rejects a tool call instead of waiting for approval.[1] For unattended agents such as cron jobs, this is the right setting: a run no longer hangs for hours on a prompt.

It's Tuesday, November tenth. Last night Anthropic released Claude Fable five point two. It costs eight dollars per million input tokens and forty dollars for output, twenty percent less than its predecessor.

On Anthropic's own coding table, FrontierCode, Fable five point two scores forty-nine point one percent, and Opus five point five forty-five point five. Those are vendor numbers at the highest thinking level, and in the same table Gemini ran only at a medium level. There's no number yet for SWE-bench Verified.

The independent site Artificial Analysis ranks the model number one out of seventy-four. But there, a single task takes forty-six minutes on average and costs twenty-six dollars. The model generates almost four times as many tokens as the average. So cheaper per token doesn't mean cheaper per task. Try it yourself on a real task at two thinking levels.

More important for your daily work: Claude Code two point one point three twenty-one closes two security holes. An MCP server using OAuth could pass your refresh tokens to a foreign server during a redirect. And a read-only Bash command could run outside the sandbox without asking. Version three twenty-two already arrived today. So: run claude update.

Quickly, a few more items: for Kimi K three point one Pro, Artificial Analysis measures sixty-seven percent on Terminal-Bench, just above Moonshot's own figure. OpenAI released a cyber model, but no new Codex model. And OpenHands is at version one point thirty-eight today.
