llm 0.37.2: your OpenAI key could wander off

On Nov 11, Simon Willison released a security version of his command-line tool llm. His description: “Two bugs could send a configured OpenAI API key to other OpenAI-compatible providers.”[1] There are two security advisories for it, GHSA-v9h7-jj4g-f862 and GHSA-r639-rr7r-x72w.[1]

OpenAI-compatible provider: Many services and local servers speak the same “language” as the OpenAI API, so the same tools work with them. Examples are local model servers or cheap hosters. It is like a universal charging cable. The bug here: the tool also plugged your OpenAI key into foreign sockets.

Why it matters to you: if you use llm alongside a local model or a third-party provider with an OpenAI interface, you have exactly the setup where the bug applies. The recipient does not have to be malicious. But a key in someone else's logs is a key you no longer control.

My take: this is the second hole of this kind in one week. Claude Code 2.1.321 from Nov 9 fixed a similar bug: MCP OAuth requests sent secrets such as refresh tokens to a different host when a server redirected them.[2] The pattern is the same. Tools that talk to many providers mix up who may receive which key. The more providers you bundle in one tool, the more these updates matter.

Try it Update llm to 0.37.2, then check your key's usage in the OpenAI dashboard for unknown calls. Why: the update closes the hole only going forward. Whether the key has already leaked, you can only see there.

Gemini 4 Carbon in Copilot: model choice becomes a price question

GitHub reports on Nov 10: “Gemini 4 Carbon is available to Copilot Pro+, Max, Business, and Enterprise users.”[1] The rollout is gradual, so you may not see the model in the picker yet. Billing is “at provider list pricing under usage-based billing”.[1] One day earlier, Claude Fable 5.2 arrived in Copilot.[2] We did not read the content of that post, only the title.

  • Carbon today: $2 / $10 per million input/output tokens.[3]
  • Carbon from Dec 1: $4 / $20.[3]
  • Fable 5.2: $8 / $40.[4]
Sourcing: The Carbon prices still appear only with Simon Willison. We did not find a Google primary source today either. GitHub names no figure, only “provider list pricing”. Check the price before you plan around it.

My take: the “list pricing” detail matters more than the new model. With usage-based billing at the provider's price, every model choice in Copilot becomes a cost question. Then the same math applies in Copilot as in Claude Code or Cursor. The upside for you: you can test Carbon and Fable 5.2 side by side in the same editor, without two accounts. The downside: from December you pay double for Carbon, and Copilot simply passes the price jump on to you.

Try it If you have a suitable Copilot plan: give the same task to Carbon once and to Fable 5.2 once, and compare the costs in the usage overview. Why: this tests without a new API key while the introductory price applies.

Claude Code: quiet, but a deadline in view

No new version since yesterday. The current one is 2.1.322 from Nov 10, with Fast Mode on Vertex AI in the regions global, us and eu. If Vertex refuses, Claude Code falls back to normal speed.[1] The version before, 2.1.321, makes Fable 5.2 the default Fable model, with 1 million tokens of context.[1]

Deadline: According to the Claude Code release notes, Fast Mode for Opus 4.8 has been deprecated since Oct 30 and goes away on Nov 30, 2026. After that, Fast Mode requests return an error with no fallback to standard Opus 4.8. Anthropic recommends moving to Opus 5.5. Check it if you have hard-wired Opus 4.8 with Fast Mode in scripts.
Fast Mode: The model answers faster, and you pay more per token for it. It is like express shipping: the same package, there sooner, more expensive.

My take: quiet from Claude Code after three releases between Nov 6 and Nov 10 is normal. If the Opus 4.8 deadline holds, it only matters for you where a model name is hard-coded in a configuration. That is exactly where such a removal only shows up once a nightly run fails.

Try it Search your repos and scripts for hard-coded model IDs, for example with grep -rn "opus-4-8". Why: a minute of searching spares you a broken agent run on Dec 1.
