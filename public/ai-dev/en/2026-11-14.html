Claude Code 2.1.325: security fix when unpacking

The only new coding release since yesterday morning: Claude Code 2.1.325. GitHub shows Nov 13 at 8:40 PM, but with no year and no time zone. The release tracker releasebot saw it first on Nov 14, 2026. The release notes say: "Fixed a security issue in how zstd-compressed responses are decoded".[1]

zstd compression: zstd (Zstandard) is a packing format like ZIP, only faster. Servers use it to shrink responses so less data travels over the wire. Your client has to unpack them again. Classic security holes appear exactly at the unpacking step: a crafted package can crash the unpacker, eat a huge amount of memory ("zip bomb"), or trigger something worse.

What the notes do not say: how serious the problem was, who could exploit it, and whether there is a CVE number. We found no CVE and no advisory. So we do not call it one. Only the location is clear: it concerns responses that Claude Code receives. That affects every session, not an exotic feature.

My take: an agent that runs code and writes files is a rewarding target. Any hole in the path through which data flows into it is more serious than in an ordinary CLI tool. I like that Anthropic names the fix in its own release line instead of hiding it in "bug fixes". An advisory with a severity rating would be better. Until there is one, I treat this as "update now" and not as "someday".

Try it Run claude update and check with claude --version that at least 2.1.325 is running. Why: it costs one minute, and security fixes are the one case where "later" is the wrong answer. This applies especially if you run Claude Code behind your own gateway or proxy.

Week in review: what this week means for your setup

Four Claude Code releases in one week, a new top model and a new Gemini family. Here is what stays with you, in the order in which it changes your daily work.

  • Fable 5.2 as the new default (Nov 9) — Claude Code 2.1.321 makes claude-fable-5-2 the default Fable model: 1M context, $8 / $40 per million tokens, cache reads $0.20.[1] It leads the Artificial Analysis general index with 65 points.[2]
  • Code Mode (Nov 12) — in opt-in mode, Claude writes JavaScript to call its tools.[1] Two days later there are still no numbers on speed or cost. My assessment from yesterday stands: the most interesting harness idea of the week, but test it in a throwaway repo first.
  • Auto Mode behind gateways (Nov 6) — when telemetry or feature flags are off, for example behind an LLM gateway, Claude Code now asks or refuses if the server cannot check a call. There is no fallback to the built-in classifier anymore.[1] If you run Claude Code through your own proxy, you will see more prompts as a result. That is by design, not a bug.
  • Fast Mode on Vertex (Nov 10) — in the regions global, us and eu, with a fallback to normal speed.[1]
  • Managed Agents self-hosted (Nov 12) — private beta.[3] Nothing for you to try today, but an argument for customers with strict data rules.

My take: the week belongs to Anthropic, but not because of Fable 5.2. You notice a stronger model in individual sessions. Code Mode and the stricter Auto Mode rule, on the other hand, change how the agent works and what it may do without you. Those are the changes you should know before they surprise you.

Gemini 4: Hydrogen now has a full price

Yesterday we were missing the output price of Gemini 4 Hydrogen. Simon Willison gives it in the entry for llm-gemini 0.37 from Nov 12: $1.50 input, $0.075 for cached input and $7.50 output per million tokens. He calls Hydrogen "the lowest cost member of the Gemini 4 family".[1] Hydrogen is the new model in the free tier and, according to Willison, powers the AI features of Google Search.[1]

For Carbon and Argon, $2 / $10 applies through Nov 30, then $4 / $20 from Dec 1.[1] Willison's pelican test (have it draw an SVG) shows the gap in everyday use: Hydrogen on a high setting cost 3.99 cents in 19 seconds, Carbon 20.31 cents in 4 minutes 11 seconds.[1] That is a single task, not a benchmark, but an honest feel for the order of magnitude.

"Cheapest Gemini 4" does not mean cheap. According to Willison, Hydrogen costs about 15 times as much as the models at $0.10 / $0.50, that is Claude Haiku 5.5 and GPT-6 Luna.[1]

My take: Hydrogen sits in an awkward middle. For an agent's routine steps there are much cheaper models, for hard decisions stronger ones. It only gets interesting if it is clearly better at coding than Haiku 5.5 or Luna. We have no number for that. Carbon remains the more exciting test subject until the end of the month, because the price doubles after that.

Try it Give Carbon and Hydrogen the same small task from your backlog and compare result, time and cost. Why: through Nov 30 the Carbon part of the test costs half, and Willison's numbers show that the gap can be large.

Open weights: many names, little confirmed data

Several coding models are floating around the open-weights thread this week. The problem: for most of them we only have search hits, no confirmed date and no independent measurement.

  • Poolside Laguna S 2.1 — 118 billion parameters, open weights on Hugging Face, OpenMDW-1.1 license, for agentic coding. It is said to fit on a single DGX Spark.[1] The source does not show the date.
  • JetBrains Mellum 2 — an MoE coding model, now open source.[2] Date also unclear.
  • Ripple-65B Preview (Nov 4) — Apache 2.0, weights on Hugging Face. The 80.5% on TerminalBench 2.1 comes from the vendor itself.[3]
MoE (Mixture of Experts): One large model made of many small sub-models ("experts"). For each word, only a few of them compute. So the model holds a lot of knowledge but needs only a fraction of the compute per answer. For you locally, that means it needs a lot of memory but runs faster than the total size suggests.

My take: 118 billion parameters on a single device is the most interesting number here for local coding. For a normal laptop with Ollama it is still too big. For Qwen, DeepSeek and Ollama we found no new coding release this week. So if you work locally, you miss nothing by waiting until Ollama builds and the first independent tests are out.
