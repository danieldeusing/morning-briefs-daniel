Gemini 4 Neon: Google's own coding numbers

On Friday we knew Neon only from Simon Willison's post. Now we could read Google's announcement of Nov 18 ourselves.[1] The sentence that matters: Neon ranks "#1 overall on the Artificial Analysis Coding Agent Index (58.6)".[1] InfoWorld repeats the same number on Nov 19, but again only as a statement from Google.[2]

The problem: yesterday the VKTR report said that Claude Code with Fable 5.2 or Opus 5.5 scores 58 points on this index.[3] 58.6 against 58 is a gap that rounding alone can produce. The Artificial Analysis page shows its values only via JavaScript. Our fetch returned the heading "Coding Agent Index v2.1" and the note "15 of 40 models", but no numbers.[4] So we cannot directly confirm either number.

Terminal-Bench: A test in which the model has to solve real tasks on a command line: build packages, analyze logs, set up servers. Like a hands-on exam in the workshop instead of a multiple-choice test.

The most interesting row is the bottom one. On SWE-sweep, a test Google does not explain in the sentences we read, Neon scores 12.8% with the lean mini-SWE harness. In its own tool Antigravity it "more than triples to a state-of-the-art 39.0%".[1] Google itself writes that this shows "what the Antigravity harness unlocks".[1]

Harness: The program around the model: it gives the model tools, reads files, runs tests and decides when an attempt is done. mini-SWE is a deliberately minimal harness, Antigravity is Google's full agent tool. Like the same chef once with a camping stove and once in a professional kitchen.
Caveat Every number in this section comes from Google. We found no entry for Neon on SWE-bench Verified, LiveCodeBench or LMArena. The AA values cannot be retrieved because the page loads via JavaScript. In the sentences we read, Google does not say which harness produced the 58.6. That is why there is no bar chart today.

What Google says about price, on the other hand, is clear: $3 per million input tokens, $0.15 for cached input, $15 per million output tokens and a context of one million tokens.[1] Neon is supposed to cost 32% less per task than Carbon.[1] Until Nov 30 that probably does not hold, because Carbon still runs at the promo price of $2 / $10.[5] Neon is available in the Gemini API via AI Studio and, for paying AI Pro and Ultra customers, in Antigravity.[1]

My take: the line "#1 overall" is marketing for a tie. The real news is in Google's own footnote: the same model achieves three times as much when the tool around it is better. That confirms what the AA index already showed yesterday. For you this means: testing Neon in Antigravity says little about how Neon runs in your Claude Code or your own harness. Anyone who wants to compare has to keep the tool the same and swap only the model. At $3 / $15, Neon sits between Sol and Fable on price. That makes it interesting for long agent runs, if the quality is confirmed independently.

Try it If you have a harness that supports several providers: run one real task once with Neon and once with your default model, in the same tool. Why: only that separates the model effect from the harness effect that Google itself shows so clearly.

Sunday experiment: Code Mode in Claude Code

Since v2.1.323 of Nov 12, Claude Code has Code Mode: "an experimental opt-in in which Claude writes JavaScript to call its tools".[1] Since v2.1.326 of Nov 16, it can also be switched on with Agent Teams.[1] During the week there is often no time to try something like this. Today it fits.

Code Mode: Normally the model calls a tool, waits for the result, reads it and calls the next tool. Every step is its own round. In Code Mode the model instead writes a small program that calls several tools in sequence and processes the results itself. Like the difference between five separate calls to the contractor and one note listing all five jobs.

The possible benefit: fewer rounds and fewer intermediate results in the context when a task needs many small tool calls. The risk shows in the note for 2.1.329: an infinite loop in Code Mode that filled up memory was stopped by a limit.[2] So the feature really is experimental.

My take: Code Mode pays off most for tasks with many similar steps, such as "read these twenty files and collect all TODOs". For single, careful changes to production code I would stay with normal mode. There you see every step individually.

Try it Turn on Code Mode in a throwaway repo and give it the same collection task once with and once without. Compare duration and token usage. Why: afterwards you know whether the opt-in is worth it for your daily work, before it becomes the default.

Claude Code: are you on at least 2.1.325?

The latest version is still v2.1.330 of Nov 20; when we checked on Sunday there was nothing newer.[1] But the most important reason to update is a week old. v2.1.325 of Nov 13 contains two security fixes:[1]

  • "Fixed a security issue in how zstd-compressed responses are decoded."
  • "Fixed some deny and ask rules not applying to certain Bash commands."
deny/ask rules: In the settings you define which commands Claude Code may never run (deny) and which it must ask about first (ask). Like a child lock on the stove. The fix means: for some Bash commands, the lock did not engage.

v2.1.329 of Nov 19 fits here: the trust dialog now shows where a folder's hooks are declared.[1] So anyone opening someone else's repo can see where automatically running commands come from.

My take: anyone who relies on deny rules to keep an agent in check and is still on a version before 2.1.325 has a false sense of security. claude --version takes one second.

It's Sunday, November twenty-second. A quiet day: no new releases from the big vendors over the weekend. The only news is that we could now read Google's own page on Gemini four Neon.

A different figure from Google is more interesting. On the SWE-sweep test, Neon scores just under thirteen percent with a lean harness, and thirty-nine percent in Google's own tool, Antigravity. Same model, three times the success. So the tool around the model matters at least as much as the model itself. Neon costs three dollars per million input tokens and fifteen dollars per million output tokens.

For your Sunday, an experiment: since mid-November, Claude Code has an experimental Code Mode. Claude writes a small JavaScript program that calls several tools at once. Try it in a throwaway repo with a collection task, and compare run time and token usage.

One security note: version two point one point three two five, from November thirteenth, closed a hole in how compressed responses are decoded. Some deny and ask rules also failed to apply to certain Bash commands. If you're on an older version, update.
