Claude Code 2.1.317: tres pequeños resguardos para agentes

El release de hoy no es una lluvia de funciones. Cierra tres huecos que se notan sobre todo cuando un agente corre sin supervisión.[1]

1 · Confirmación antes de enviar tu correo electrónico

Textualmente: "Added a check that asks before a web or shell tool call sends your account email address to the network".[1] El escenario detrás: una página web o un archivo del repositorio contiene instrucciones ocultas, y el agente incrusta tu dirección en una llamada curl o en una URL. Ahora Claude Code pregunta antes.

Prompt injection: Texto que el agente lee mientras trabaja (una página web, un README, un issue) y que suena como una instrucción para él. El modelo no siempre distingue si tú quieres algo o si solo es un texto ajeno que lo finge. Es como una nota dentro del paquete, "Por favor envía la factura a esta dirección", que el almacenista simplemente obedece.

Mi opinión: bueno, pero limitado. La verificación reconoce exactamente un valor, la dirección de tu cuenta. Claves de API, datos de clientes o fragmentos de código no los cubre, según el texto del changelog. Para esos siguen encargándose el sandbox y las reglas de red. Lee la pregunta como un detector de humo: cuando aparezca, revisa qué texto llevó al agente a hacerlo.

2 · Hooks que bloquean ante un error

El Agent SDK incorpora onFailure: "block", "so a callback that fails blocks the action instead of letting it run".[1] Hasta ahora, si tu callback de verificación se caía, la acción se ejecutaba de todos modos.

Fail-open vs. fail-closed: ¿Qué pasa cuando el propio vigilante falla? Fail-open significa: la puerta queda abierta. Fail-closed significa: la puerta queda cerrada. Un cadenero que se desmaya no debería abrirle el antro a todo el mundo.

Pruébalo Si usas un hook en el SDK como verificación de seguridad (por ejemplo, "ningún git push a main"), configura onFailure: "block". Por qué: un vigilante que deja pasar todo en silencio ante un timeout no es vigilante. Para hooks que solo registran no vale la pena; ahí un bloqueo solo estorbaría.

3 · claude -p avisa de escrituras perdidas

Hasta ahora, claude -p terminaba con código de salida 0 incluso cuando un disco lleno o una cuota se había tragado la transcripción o ~/.claude.json. Ahora hay un mensaje de error y, con salida en texto y JSON, código de salida 1.[1] Para cron jobs y CI significa que una ejecución que perdió datos en silencio ahora se nota. Revisa que tus scripts aborten bien con exit 1 y no caigan en un ciclo de reintentos.

Como recordatorio

  • Fast Mode de Opus 4.8: a partir del 30/11 regresa un error, "and do not fall back to standard Opus 4.8". El reemplazo es Opus 5.5.[1] Faltan 27 días.
  • Protección de escritura de 2.1.314 (30/10): permissions.blockWritesOutsideWorkingDirectories bloquea Write, Edit y NotebookEdit fuera de tus carpetas de trabajo, en cualquier modo.[1] Ese interruptor lo recomendamos ayer.
  • Effort de subagentes de 2.1.316: CLAUDE_CODE_SUBAGENT_EFFORT define con qué effort corren los subagentes cuando nada más lo indica.[1]

Kimi K3.1 Pro: la fecha es mañana

Moonshot ofrece Kimi K3.1 Pro por API desde el 23/10, a US$ 2 por millón de tokens de entrada y US$ 10 por millón de tokens de salida en la tarifa estándar. Los pesos están "planned for release on November 4".[1] Eso es mañana.

El panorama de ayer no cambió. El anuncio no menciona licencia ni valores de benchmark.[1] Circulan cifras de Terminal-Bench para Kimi, pero no pudimos confirmar ninguna en una fuente cargada. Por eso no citamos ninguna.

Mi opinión: el modelo es demasiado grande para tu computadora. Kimi es interesante como modelo abierto que los proveedores de hosting pueden ofrecer barato. Mañana fíjate en tres cosas: la licencia, si la versión abierta es el mismo modelo que el de la API y qué tan rápido lo ofrecen terceros por debajo del precio de Moonshot. Informamos el jueves.

OpenAI: crédito de API para suscriptores de ChatGPT

En el changelog de la API del 28/10 dice: "Eligible ChatGPT Pro and Business subscribers can now claim up to $500 per month in free API credits."[1] Quién cumple las condiciones no aparece en la entrada. "Up to" además significa: US$ 500 es el tope, no el caso normal.

Mi opinión: es un anzuelo para justo tu público. Quien ya tiene una suscripción a ChatGPT ahora puede probar GPT-6.1 Terra en un harness propio o en Cline sin pagar extra. Según OpenAI, Terra cuesta US$ 1 por millón de tokens de entrada y US$ 5 por millón de tokens de salida.[2] Con US$ 500 rinde mucho. El valor de 50,3 % en Terminal-Bench 4.0 con esfuerzo máximo lo midió la propia OpenAI.[2] No encontramos una medición independiente.

Pruébalo Si tienes Pro o Business: solicita el crédito y corre Terra en dos o tres tareas reales de tu repositorio contra tu modelo estándar. Por qué: un modelo barato y rápido para tareas rutinarias ahorra dinero, y la prueba no te cuesta nada.

No es de programación, pero está en el mismo changelog: GPT-6 Rosalind (30/10) es un modelo de biología solo para investigadores verificados.[1]

Hoy es martes tres de noviembre. De domingo a hoy no salió ningún modelo nuevo de programación, ni de Anthropic, ni de OpenAI, Google o Cursor. La única novedad es un pequeño release de Claude Code.

La versión dos punto uno punto trescientos diecisiete trae tres resguardos. Primero, Claude Code ahora pregunta antes de que una llamada web o de shell envíe a la red el correo electrónico de tu cuenta. Eso protege contra textos que le cuelan instrucciones ocultas al agente. Pero la verificación solo reconoce esa dirección, no por ejemplo las claves de API.

El Agent SDK incorpora un modo de hook que bloquea ante un error. Hasta ahora, si tu callback de verificación se caía, la acción seguía su curso. Quien use hooks como verificación de seguridad debería activar este modo. Además, el modo de línea de comandos ahora termina con un código de error cuando un disco lleno se traga la transcripción. Para los cron jobs es una buena noticia.

Como recordatorio: el modo rápido de Opus cuatro punto ocho desaparece el treinta de noviembre. Faltan veintisiete días.

Mañana Moonshot quiere liberar los pesos de Kimi K tres punto uno Pro. La licencia y los valores de benchmark siguen abiertos. Fíjate sobre todo en si la versión abierta es el mismo modelo que el de la API.

OpenAI da a los suscriptores de ChatGPT Pro y Business hasta quinientos dólares al mes en crédito de API. Con eso se puede probar gratis, en tareas reales, el económico GPT-seis punto uno Terra. Eso sí, sus valores de benchmark vienen de la propia OpenAI.

En benchmarks, hoy no hay mediciones independientes nuevas. Y en Cursor, Cline, OpenHands, Continue y Aider todo está en calma. El jueves veremos qué publicó realmente Kimi.
