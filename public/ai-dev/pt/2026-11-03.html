Claude Code 2.1.317: três pequenas proteções para agentes

O release de hoje não é uma chuva de recursos. Ele fecha três brechas que aparecem sobretudo quando um agente roda sem supervisão.[1]

1 · Confirmação antes do envio do seu e-mail

Literalmente: "Added a check that asks before a web or shell tool call sends your account email address to the network".[1] O cenário por trás: uma página web ou um arquivo do repositório contém instruções escondidas, e o agente embute o seu endereço em uma chamada curl ou em uma URL. Agora o Claude Code pergunta antes.

Prompt injection: Texto que o agente lê enquanto trabalha (uma página web, um README, uma issue) e que soa como uma instrução para ele. O modelo nem sempre consegue distinguir se é você quem quer algo ou se é só um texto de fora fingindo. É como um bilhete dentro da caixa, "Por favor, envie a nota fiscal para este endereço", que o funcionário do estoque simplesmente obedece.

Minha opinião: bom, mas restrito. A verificação reconhece exatamente um valor, o endereço da sua conta. Chaves de API, dados de clientes ou trechos de código ela não cobre, segundo o texto do changelog. Para esses, continuam valendo o sandbox e as regras de rede. Leia a pergunta como um detector de fumaça: quando ela aparecer, veja qual texto levou o agente a isso.

2 · Hooks que bloqueiam em caso de erro

O Agent SDK ganha onFailure: "block", "so a callback that fails blocks the action instead of letting it run".[1] Até agora, se o seu callback de verificação travasse, a ação rodava mesmo assim.

Fail-open vs. fail-closed: O que acontece quando o próprio vigia cai? Fail-open significa: a porta continua aberta. Fail-closed significa: a porta continua fechada. Um segurança que desmaia não deveria abrir a balada para todo mundo.

Experimente Se você usa um hook no SDK como verificação de segurança (por exemplo, "nenhum git push na main"), defina onFailure: "block". Por quê: um vigia que deixa tudo passar em silêncio num timeout não é vigia. Para hooks só de log não vale a pena; lá um bloqueio seria apenas incômodo.

3 · claude -p avisa sobre gravações perdidas

Até agora, claude -p terminava com código de saída 0 mesmo quando um disco cheio ou uma cota tinha engolido a transcrição ou o ~/.claude.json. Agora há uma mensagem de erro e, com saída em texto e JSON, código de saída 1.[1] Para cron jobs e CI, isso significa que uma execução que perdeu dados em silêncio agora chama atenção. Verifique se os seus scripts abortam direito com exit 1 e não caem em um loop de retry.

Para lembrar

  • Fast Mode do Opus 4.8: a partir de 30/11 volta um erro, "and do not fall back to standard Opus 4.8". O substituto é o Opus 5.5.[1] Faltam 27 dias.
  • Proteção contra gravação da 2.1.314 (30/10): permissions.blockWritesOutsideWorkingDirectories bloqueia Write, Edit e NotebookEdit fora das suas pastas de trabalho, em qualquer modo.[1] Recomendamos essa chave ontem.
  • Effort de subagentes da 2.1.316: CLAUDE_CODE_SUBAGENT_EFFORT define com qual effort os subagentes rodam quando nada mais o determina.[1]

Kimi K3.1 Pro: o prazo é amanhã

A Moonshot oferece o Kimi K3.1 Pro pela API desde 23/10, por US$ 2 por milhão de tokens de entrada e US$ 10 por milhão de tokens de saída na tarifa padrão. Os pesos estão "planned for release on November 4".[1] Isso é amanhã.

O quadro de ontem não mudou. O anúncio não menciona licença nem valores de benchmark.[1] Circulam números de Terminal-Bench para o Kimi, mas não conseguimos confirmar nenhum deles em uma fonte carregada. Por isso não citamos nenhum.

Minha opinião: o modelo é grande demais para a sua máquina. O Kimi é interessante como modelo aberto que hosters podem oferecer a preço baixo. Amanhã, observe três coisas: a licença, se a versão aberta é o mesmo modelo da API e a rapidez com que terceiros o oferecem abaixo do preço da Moonshot. Voltamos ao assunto na quinta-feira.

OpenAI: crédito de API para assinantes do ChatGPT

No changelog da API de 28/10 consta: "Eligible ChatGPT Pro and Business subscribers can now claim up to $500 per month in free API credits."[1] Quem cumpre as condições não está dito na entrada. "Up to" também significa: US$ 500 é o teto, não o caso normal.

Minha opinião: é uma isca para exatamente o seu público. Quem já tem uma assinatura do ChatGPT agora pode testar o GPT-6.1 Terra em um harness próprio ou no Cline sem pagar a mais. Segundo a OpenAI, o Terra custa US$ 1 por milhão de tokens de entrada e US$ 5 por milhão de tokens de saída.[2] Com US$ 500 dá para ir longe. O valor de 50,3% no Terminal-Bench 4.0 com esforço máximo foi medido pela própria OpenAI.[2] Não encontramos uma medição independente.

Experimente Se você tem Pro ou Business: peça o crédito e rode o Terra em duas ou três tarefas reais do seu repositório contra o seu modelo padrão. Por quê: um modelo barato e rápido para tarefas de rotina economiza dinheiro, e o teste não custa nada.

Não é sobre código, mas está no mesmo changelog: o GPT-6 Rosalind (30/10) é um modelo de biologia apenas para pesquisadores verificados.[1]

Hoje é terça-feira, três de novembro. De domingo até agora, nenhum modelo novo de código foi lançado, nem pela Anthropic, nem pela OpenAI, pelo Google ou pela Cursor. A única novidade é um pequeno release do Claude Code.

A versão dois ponto um ponto trezentos e dezessete traz três proteções. Primeiro, o Claude Code agora pergunta antes de uma chamada web ou de shell mandar o e-mail da sua conta para a rede. Isso protege contra textos que enfiam instruções escondidas no agente. Mas a verificação só reconhece esse endereço, e não, por exemplo, chaves de API.

O Agent SDK ganha um modo de hook que bloqueia em caso de erro. Até agora, se o seu callback de verificação travasse, a ação seguia em frente. Quem usa hooks como verificação de segurança deveria ligar esse modo. Além disso, o modo de linha de comando agora termina com código de erro quando um disco cheio engole a transcrição. Para cron jobs, é uma boa notícia.

Para lembrar: o modo rápido do Opus quatro ponto oito acaba no dia trinta de novembro. Faltam vinte e sete dias.

Amanhã a Moonshot quer liberar os pesos do Kimi K três ponto um Pro. Licença e valores de benchmark ainda estão em aberto. Fique de olho principalmente em saber se a versão aberta é o mesmo modelo da API.

A OpenAI dá a assinantes do ChatGPT Pro e Business até quinhentos dólares por mês em crédito de API. Com isso dá para testar de graça, em tarefas reais, o barato GPT-seis ponto um Terra. Os valores de benchmark dele, porém, vêm da própria OpenAI.

Nos benchmarks, hoje não há medições independentes novas. E está tudo quieto em Cursor, Cline, OpenHands, Continue e Aider. Na quinta-feira vamos ver o que o Kimi realmente publicou.
