87 €/h para Java — e por que 100 €/h continua fazendo sentido [3][4][5]

Hoje há um número específico de Java: o freelancermap indica para Java uma média de 87 €/h. Mas a página não diz quando nem como foi medida. Por isso é um valor de referência, não uma estatística.[3] Mais sólida é a análise de 24/09/2026: desenvolvedores de software freelance na região DACH cobram em mediana 90 € líquidos por hora, quase todas as tecnologias ficam entre 85 e 90 €.[4] Um guia indica para Java/Spring Boot 85–120 €/h. Só vi esse número como snippet de busca.[5]

Taxa pedida: Esses números vêm de perfis — é o que freelancers pedem, não o que os clientes pagam no fim. Como etiquetas de preço na vitrine: mostram o mercado, mas não o desconto no caixa.

Nenhuma das dez páginas do topo informa uma taxa. Todas pedem ao candidato o valor da sua hora. As taxas no board com * são, por isso, estimativas (85–130 €/h).[2]

Minha avaliação: Manter 100 €/h para Java/Angular. São 13 € acima da média de Java — justificável com fullstack de uma só mão, mais de 13 anos de experiência e disponibilidade imediata. Na Amoria Bond, 110 €/h, porque IoT mais Java é raro. Recusar abaixo de 90 €/h.
