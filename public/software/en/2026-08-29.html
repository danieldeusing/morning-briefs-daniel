PaperCut: the second emergency patch arrived the same day as the first

PaperCut published an advisory on 08/27 and followed up on 08/28 with emergency patches for branches 25 and 26, with branch 24 following the same day. Behind it are two CVEs: CVE-2026-81578, an authentication bypass (CVSS v4 8.8, CWE-306), and CVE-2026-82078, insecure dynamic class loading (CVSS v4 9.4, CWE-470). The vendor is treating all NG and MF versions as potentially affected for now and, according to Rapid7, is handling the case as a "security emergency" with confirmed customer incidents — the chain could only be reproduced with material from a university customer's forensics team.

Dynamic class loading: Java programs can decide at runtime which code to load — based on a name stored in the configuration. Like a restaurant that changes the recipe on request: as long as only the kitchen can make the request, that's convenient. If the guest can too, the guest is doing the cooking.

The path is described plainly: the bypass allows calling privileged components, which lets an external database lookup be reconfigured, and once that's triggered, foreign SQL runs — ending in code execution. On 08/28, PaperCut followed up again because researchers found ways around the first fix; the second patch brings "additional hardening beyond the original emergency patch."

Heads up If you patched Thursday morning, you're on the first fix — only checking against the current advisory helps here. And a patch doesn't clean up after itself: the external lookup needs checking afterward just as much as the credentials attached to it.

My take: This is PaperCut's second round. CVE-2023-27350 (CVSS 9.8) landed in the KEV catalog on 04/21/2023, CISA and the FBI wrote a joint advisory (AA23-131A), and the Bl00dy ransomware gang used it to go after the education sector specifically. That a university is reporting again today is no coincidence: print management sits everywhere in universities and hospitals, hangs off the directory service, holds database credentials — and nobody has it on their radar because it's "just printing." So the useful question isn't "do I have PaperCut," but "what else on my network sits in this same category."

Next.js: 9.0 on Windows, no workaround

The Next.js team released a security update on 08/25 that closes two critical flaws. The first, CVE-2026-75604 (CVSS 9.0), is a path traversal in the Windows file system that leads to unauthenticated code execution. Affected are applications using both Pages Router and App Router without Cache Components, in versions 13.4 through 15.5.23 and 16.0 through 16.3.2; fixed in 15.5.24 (Maintenance LTS) and 16.3.3 (Active LTS). Linux and macOS servers are not affected, and there is no workaround.

Path traversal: A program builds a file path out of something the user sent. Anyone who sneaks in "go up one directory" climbs out of the folder it was meant to stay in — like a mailing address that says "and then three doors down" instead of an apartment number, and the mail carrier actually follows it.

The second flaw doesn't come from Next.js at all, but from libheif: a heap overflow (CVSS 9.5) in heif_decode_image(), which Next.js inherits through its image optimization whenever AVIF is involved. Deployments hosted on Vercel are unaffected, according to the vendor.

My take: Two things stand out here. First, the condition "Pages Router and App Router together" — the state of every half-finished migration, which is to say the normal case in projects that have grown organically. Second, the AVIF flaw: it sits in a C library three layers below the framework and shows up nowhere in package.json. Anyone who only checks direct dependencies never sees cases like this — npm ls next answers the first question in seconds; only an update answers the second.

KEV status: Citrix today, two more tomorrow

Citrix NetScaler — the deadline ends today

The CISA deadline for US federal agencies for CVE-2026-8452 in NetScaler ADC and Gateway expires today. The vendor classified the flaw in late June as a memory overflow leading to a crash, an external analysis in mid-August showed full unauthenticated code execution, and webshells have already been found on appliances. Formally the deadline applies only to US agencies — everywhere else it's a prioritization signal.

Gitea: 8,300 open instances

For CVE-2026-60004, whose deadline expired yesterday, Shadowserver delivers the recount: over 8,300 internet-reachable Gitea instances remain unpatched, even though the fix has been available since late July in 1.27.1. Getting in stays easy because Gitea enables self-registration by default — turning "needs an account" into effectively "needs nothing." Crypto miners have been observed on unpatched servers.

Recent additions as of the 08/27/2026 catalog snapshot: CVE-2023-49105 (ownCloud) and CVE-2026-53362 (Linux kernel), deadline tomorrow, plus CVE-2026-66384 (JFrog Artifactory), deadline 09/10.

ServiceNow: three critical flaws, no known exploitation

ServiceNow published four CVEs on 08/27, three of them critical: CVE-2026-18885 (code injection with code execution and data access), CVE-2026-18886 (code injection with privilege escalation), and CVE-2026-74820 (SQL injection) — the first two in the AI Platform. Plus CVE-2026-6876, a sandbox escape in the Now Platform, rated "high" by the vendor. Fixed across the Xanadu, Yokohama, Zurich, and Australia release families. The vendor writes: "We are not currently aware of malicious exploitation against ServiceNow instances."

On the number: several trade outlets headline this as "CVSS 10.0." BleepingComputer's report names no numeric scores, and I did not open the vendor advisory — hence "critical" here rather than a score. What makes this uncomfortable is the context: CVE-2026-6875, from the same platform, was exploited in July. Where half the organization keeps its tickets, assets, and access requests, "no known exploitation yet" is a snapshot with a short shelf life.

Routers with factory backdoors: "Endlessdoors"

Researchers found three factory-installed implants in OEM routers made by the Chinese manufacturer ZBT/Zbtlink. The most conspicuous one, dubbed "Endlessdoors," starts with the device, allows unauthenticated command execution as root, and opens a plaintext TCP connection to a China-registered domain every 35 seconds. Over 20 models from Zbtlink and Wiflyer are affected, resold worldwide under other brands. VulnCheck estimates at least 100,000 devices in use.

C2 beacon: A piece of malware calls its operator at fixed intervals and asks "anything to do?" — like an intern who checks in with the boss every thirty seconds. The trick: the call goes from inside out, and firewalls almost always let outbound connections through.

My take: The number that sticks is the 35 seconds — not a maintenance backdoor held in reserve for an emergency, but continuous plaintext traffic that any serious network monitoring would spot immediately. So this is more a story about the procurement path than about technology: these devices sit under other brands' names in small businesses and industrial plants, and nobody there is watching outbound connections.

CRA: 13 days to the reporting duty — and no API

On 09/11, the first hard deadline of the EU Cyber Resilience Act kicks in: actively exploited vulnerabilities and severe incidents go to ENISA and the national CSIRT as an early warning within 24 hours, triage follows after 72 hours, and the final report after 14 days. Submissions go through the Single Reporting Platform — which, per ENISA, has "no API at this stage." ENISA last updated its guidance on 08/03 and 08/14; as of late June the platform was not yet live.

Note "No API" means, in practice, that the 24-hour clock is running against a human filling out a web form. Anyone subject to the reporting duty should do a dry run this week to work out who decides and who types — not for the first time on September 11.

AWS acquires DuckLabs — DuckDB stays with the foundation

Amazon signed a binding agreement on 08/26 to acquire DuckLabs, the company behind DuckDB; closing is expected in early September, price undisclosed. Explicitly not part of the deal is the open-source project itself: DuckDB stays MIT-licensed under the nonprofit DuckDB Foundation, as do DuckLake and Quack. Founders Hannes Mühleisen and Mark Raasveldt are moving to AWS along with the team, will keep steering the technical direction, and will remain in Amsterdam.

My take: The foundation structure is why this isn't a cause for outcry: the brand and the rights to the core sit with a foundation, not the acquired company. The buyer gets the people and the services business, not the lever to change the license — the opposite of the Redis, HashiCorp, and Elastic pattern. The open question isn't a legal one: a project's direction follows whatever its core developers find urgent each morning. If those same people are drawing an Amazon paycheck, the focus drifts toward whatever problems their employer has — not out of ill will, but out of proximity.

€508,640 from Germany for Flatpak sandboxing

The Sovereign Tech Agency, through the Sovereign Tech Fund, is funding further development of Flatpak with €508,640. The work runs through the end of 2027 and targets the isolation layer: new portals for PipeWire audio, network isolation, a VPN portal modeled on the Android and iOS interfaces, and one for spell-checking. Organized by the Modal Collective with Para-Real Ltd.

Portal (Flatpak): An application in the sandbox can't reach the microphone or the file system on its own — it asks through a "portal," and the system asks you. Like a hotel room with no master key: you can get everywhere, but always through the front desk, and the front desk keeps a record.

My take: the least conspicuous way to spend public money on software correctly — not a flagship project, but the layer that half the Linux desktop stands on and that nobody can bill for. The network piece is the most interesting part: the sandbox model is strong on the file system and practically blind on the network, and that's exactly where the data-exfiltration question runs through. Sovereignty isn't a European cloud provider's press release — it's half a million euros into a layer that nobody else maintains.

Android 17 makes four network switches the default

Google has described a set of network hardening measures for Android 17. Four points: Encrypted Client Hello platform-wide — on by default for apps that target Android 17 and use a compatible networking library; a switch that lets carriers turn off 2G for their customers without their involvement; a new Local Network Protection permission for accessing the home network; and Certificate Transparency as the default.

Encrypted Client Hello: When connecting to a website, the content is encrypted, but the site's name sits in plaintext in the first packet — anyone along the network path can read where you're going. ECH puts the name inside the envelope too: previously the recipient was written on the outside, now it's on the inside.

The reach is notable: browsers have had ECH for years, but as a platform-wide default on a mobile operating system, this is a first — which also covers the app quietly sending telemetry in the background. The 2G point targets fake base stations that force devices down onto that old network specifically.

LibreOffice 26.8: not a word about AI, and deliberately so

The Document Foundation released LibreOffice 26.8 for Windows, macOS, and Linux on 08/26, in 120 languages. Three technical things stand out: a new Paragraph Composer that calculates justified text across multiple lines instead of line by line, automatic detection of right-to-left text, and faster opening of image-heavy documents.

The real news is in the fine print: no generative AI in this release, no document leaves the machine for processing, no component needs network access. The foundation explicitly calls this "a deliberate position" — a decision, not a lag. In a year when every office suite has bolted an assistant onto its menu bar, this is a positioning statement: for anyone working with other people's contracts and patient data, "doesn't touch the network" is a feature, not a shortcoming.

It's Saturday, August 29th. Today's story is about a print server — and what happens when a vendor patches under time pressure.

PaperCut is the software that manages printing at universities, hospitals, and large companies. On Thursday, the vendor confirmed two flaws already being exploited and shipped emergency patches. That same day, it had to push out a second emergency patch because researchers found a way around the first fix. So if you updated Thursday morning, you're only on the first version — the version number alone doesn't answer the question anymore.

Technically, two bugs work together. The first bypasses login, the second lets the program load code at runtime based on a name stored in its configuration. Combine the two, and an attacker can reconfigure an external database query, and once it fires, foreign code runs on the server. The severity score is nine point four. The vendor is treating every version as potentially affected for now, and the chain could only be reproduced using material from a university customer's forensics team — meaning this flaw came out of a real-world incident, not a lab.

This is PaperCut's second time around. Back in 2023, a PaperCut flaw already landed in the catalog of actively exploited vulnerabilities, with a joint warning from CISA and the FBI, and a ransomware gang used it to specifically target schools and universities. The broader point: print management sits everywhere, hangs off the directory service, and holds database credentials — and nobody watches it because it's "just printing." The useful question isn't "do I run PaperCut," but "what else on my network falls into this same category."

The second story points straight at your own stack. Next.js released a security update on August 25th that closes two critical flaws. The first allows code execution with no authentication at all, if the server runs on Windows, with a severity score of nine point zero and no workaround. It affects the setup where Pages Router and App Router are both in use — exactly the state of every half-finished migration. It's fixed in fifteen point five point twenty-four and in sixteen point three point three.

The second Next.js flaw is the more instructive one. It doesn't live in Next.js at all, but in a C library called libheif, which has a memory overflow when decoding AVIF images. Next.js inherits it through its image optimization. That library never shows up in the project's dependency listing — anyone who only checks their direct dependencies will never catch cases like this.

For US federal agencies, today is the deadline for the Citrix NetScaler flaw that got upgraded two weeks ago from "just crashes" to "full code execution." And for the self-hosted Git service Gitea, Shadowserver still counts over eight thousand three hundred reachable, unpatched instances — even though the fix has been available since late July. Some of them are now running crypto miners.

Two stories from open-source politics. Amazon is acquiring DuckLabs, the company behind the analytics database DuckDB. The project itself is explicitly not part of the deal: it stays MIT-licensed under a nonprofit foundation, while the two founders are moving to Amazon, will keep leading the team, and are staying in Amsterdam. Because the rights sit with the foundation rather than the company, this is the opposite of the Redis and HashiCorp pattern — a license change is structurally off the table. The open question isn't a legal one, but a matter of gravity: developers tend to work on whatever their employer urgently needs.

And from Germany: the Sovereign Tech Agency is putting a good half a million euros into Flatpak, the sandboxing layer of the Linux desktop, with work running through the end of 2027. New additions include network isolation and a VPN portal. This is the quiet way to spend public money correctly — not on a flagship project, but on the layer everything else stands on, the one nobody can bill for.

To close out, two smaller items with real substance. Factory-installed backdoors were found in OEM routers from a Chinese manufacturer, phoning home in plaintext every thirty-five seconds — an estimated one hundred thousand devices, sold worldwide under other brands. And LibreOffice twenty-six point eight has shipped, with no generative AI at all, and the foundation explicitly calls that a deliberate decision.
