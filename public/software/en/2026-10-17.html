BeyondTrust Remote Support: remote maintenance as an entry point [1][2]

BeyondTrust has closed a flaw in Remote Support (RS) that, according to BleepingComputer, has been exploited as a zero-day since late August. CVE-2026-102764 is an authentication bypass: attackers without privileges can run file operations on unpatched appliances. RS 26.2.3 and older are affected (advisory BT26-05).[1] CISA added the flaw to the KEV catalog on Oct 16; US federal agencies have until Mon Oct 19.[2]

Remote support appliance: A server that IT support uses to connect to other people's computers and work on them. Like the janitor's master key: handy, but whoever steals it can get into every apartment.

According to Mandiant/GTIG, the attacks come from a suspected Chinese espionage actor, which they call "Armory Castle" (formerly UNC5221) and CrowdStrike calls "Warp Panda". Mandiant describes a webshell (Sawfly), a tunnel (Bareclaw), deleted logs, and lateral movement with stolen admin credentials. BeyondTrust patched SaaS customers on Oct 8; self-hosted installations need the update by hand unless automatic updates are really on. Shadowserver counts over 1,400 reachable RS instances, but does not say how many of them are patched or honeypots. The report gives no CVSS score.[1]

Privileged Remote Access (PRA) shares the affected code. BeyondTrust found no way to exploit it internally, but still ships a patch and advises applying it immediately.[1]

Take Six weeks of zero-day on a device that holds credentials for half a network: the update alone is not enough. BleepingComputer advises treating every reachable appliance with a vulnerable version as "potentially compromised" until it has been checked. Our view: rotate all credentials the box stored or brokered. That is the real weekend work, not the patch.

Collabora in Nextcloud: the fix came before the warning [1]

Attackers are exploiting a flaw in Nextcloud's built-in Collabora server (richdocumentscode) to drop webshells. CVE-2026-110447 is a command injection via proxy.php, no login required. All versions before 26.4.303 are affected.[1] EU

Webshell: A small script an attacker plants on a web server to control it later through the browser. Like a spare key the burglar leaves under the doormat before he goes.

The timeline is the real point. The fix went out as a commit on Sep 9, version 26.4.303 on Sep 11. According to BleepingComputer, the first attacks came as early as Sep 10. The CVE and advisory only followed on Oct 14.[1] Our opinion: to attackers, a public commit is already the advisory. Anyone who updates Nextcloud only when a CVE is announced was a month late here.

To check According to BleepingComputer, disabling the app is not enough. Bring the version to 26.4.303 or newer, then search the webroot for foreign PHP files.
[1] bleepingcomputer.com (Oct 15)

Arch Linux: fake yay and paru packages in the AUR [1]

Packages appeared in the Arch User Repository posing as the AUR helpers yay and paru, for example as "yyay". Their install script pulls a shell script from GitFlic via a Wayback Machine URL and runs it as root. It was discovered on Oct 13; the account "marchos1as" is banned.[1]

AUR: A collection of build recipes that Arch users upload themselves and nobody checks beforehand. Like a supermarket bulletin board: often useful, but anyone can pin up a note.

BleepingComputer is clear: anyone who installed the packages should treat the system as compromised. A link to the npm campaign "DirtyBlanket" (OSV MAL-2026-17242) is possible but not confirmed. As far back as June there were around 400 AUR packages with a rootkit stealer.[1] Our view: typosquatting the very tool you use to install AUR packages is deviously elegant. Reading the PKGBUILD stays mandatory, even the third time.

[1] bleepingcomputer.com (Oct 15)

Magento "BlockStrap": critical, but still quiet [1]

According to BleepingComputer, CVE-2026-103849 in Magento and Adobe Commerce has the highest severity level. An injection in template directives allows PHP code to run on the server. According to the report, versions up to 2.4.9 and B2B up to 1.5.3 are affected. Adobe published bulletin APSB26-153 on Oct 13, but only with priority 2; Sansec disagrees with that rating. No attacks have been observed yet.[1] Our opinion: shops are a rewarding target for card skimmers. "No attacks yet" tends not to last long.

Windows October update: NTLMv1 is out, and some networks with it [1][2][3]

The October update changes the default for the registry value BlockNtlmv1SSO. If it is not set, Windows now uses enforce mode (1) instead of audit (0). SSO requests with NTLMv1 credentials are therefore blocked instead of just logged. According to The Register, this can break Wi-Fi, Ethernet and VPN sign-ins.[1]

NTLMv1: An ancient Windows sign-in method from the 1990s that is easy to crack today. Like a three-digit bicycle lock: it looks like protection, but stops no one.

Microsoft's workaround: set BlockNtlmv1SSO to 0. Microsoft itself calls this a "scoped, temporary security exception". With Credential Guard enabled, the block does not apply either.[1] Our view: this is not a bug but a deadline many people ignored. Audit mode buys time but solves nothing.

Two more trouble spots: update KB5127648 can break Smart App Control,[2] and heise reports Exchange servers failing after the October updates.[3] On Exchange we checked only the headline. As a reminder: the Oct 13 Patch Tuesday was a record with 1,411 flaws.

Deno: Ryan Dahl goes to Cloudflare [1][2]

Update since Oct 15 According to The Register, the deal is an acquihire: Dahl and 12 Deno colleagues will now work on Cloudflare Workers. The goal is a standalone JavaScript/WebAssembly runtime built from celld and workerd that works with Workers and Durable Objects.[1]

The classic Deno runtime gets one more year of bug fixes and security patches, then development ends. Dahl is looking for a new home for the MIT-licensed project, possibly the OpenJS Foundation.[1] According to heise, Deno Deploy will be shut down in six months, with migration to Workers; JSR stays.[2] Our view: anyone running Deno in production should plan the path to Node or Bun now. A year of patches is a stay of execution, not a roadmap.

It's Saturday, October seventeenth. The week ends on an uncomfortable story: the tool admins use to maintain other people's computers was itself the open door.

BeyondTrust has patched a flaw in its remote access product, Remote Support. According to BleepingComputer, it has been under attack since late August, reportedly by a Chinese espionage group. Version twenty-six point two point three and older are affected. The U.S. agency CISA added the flaw on Friday to its catalog of actively exploited vulnerabilities, and the deadline is Monday. If you run one of these devices yourself, don't just patch. Change every credential that was stored on it.

Nextcloud is under attack too. Attackers are planting webshells through the built-in Collabora server. The timeline is striking: the fix was available on September eleventh, but the official warning didn't come until October fourteenth. The first attacks hit one day after the public commit.

Fake packages showed up in the Arch User Repository, posing as the popular helpers yay and paru. Their install script downloads a foreign script and runs it with root privileges. If you installed them, treat the system as compromised. And Magento shops face a top-severity flaw called BlockStrap, with no known attacks so far.

Windows admins are wrestling with the October update. It now blocks sign-ins using the ancient NTLM version one by default. According to The Register, that can break Wi-Fi, Ethernet and VPN. Microsoft offers a temporary workaround, but itself calls it a temporary security exception.

Two follow-ups to this week's stories. On Deno, it's now clear: Ryan Dahl and twelve colleagues are joining Cloudflare. The old runtime gets one more year of patches, and Deno Deploy ends in six months. And PostgreSQL 19 is due around November nineteenth, but without eight to ten major features that now have to wait for version twenty.

In Europe, according to The Register, the Cyber Resilience Act's reporting duties have applied since September. Berlin wants seventy percent open source on its administration desktops by twenty thirty-two.

On Monday, the U.S. deadlines for BeyondTrust and Fortinet expire. The next brief will look at whether Oracle's Java patches arrive and whether the Windows problems spread further.
