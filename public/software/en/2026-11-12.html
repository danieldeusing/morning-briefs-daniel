Node, Apache, Git: a patch day in the foundations

After Patch Tuesday came the quieter but, for us, more important part yesterday: Node.js closes 16 flaws, seven of them "High," almost all in HTTP/2 and TLS. Apache httpd 2.4.71 fixes a critical flaw in mod_http2 that can reach code execution. And Git ships seven maintenance releases against six flaws, one of which leads to code execution during a recursive clone. Our take: HTTP/2 is the attack surface of the week. If you expose Node or httpd directly to the internet, patch this week. If you sit behind Caddy or another proxy, you have some breathing room, but no excuse.

Node.js: 16 flaws, most of them in HTTP/2

On Nov 11, Node.js 22.23.5, 24.22.3 and 26.13.1 arrived. They close 16 flaws: 7 "High," 6 "Medium" and 3 "Low."[1] Four of the seven severe flaws are in HTTP/2, for example a use-after-free when a respondWithFile() stream is aborted during a write (CVE-2026-123874). Another sends freed response memory to the peer (CVE-2026-123866).[1]

In TLS, one flaw is especially nasty: with a renegotiation under TLS 1.2, a client can switch the server name and so bypass the client-certificate check (CVE-2026-123872). Another makes the HTTPS server copy parts of its own heap into the response body (CVE-2026-123864).[1] The advance warning came the same day via oss-security.[2]

HTTP/2 stream: HTTP/2 sends many requests at once over a single connection, each as its own "stream." The server has to manage memory for every stream and clean it up properly when one is aborted. Like a waiter with ten tables at once: if a guest leaves mid-order, the food must not end up at the wrong table.
Our take Mainly affected is Node as a server that speaks HTTP/2 or TLS itself. An Angular or React build that only runs locally is not a target. A Node backend behind Caddy that only speaks HTTP/1.1 internally has less surface. Still: rebuilding the base images is cheap, and you do it this week.
[1] nodejs.org (Nov 11) · [2] openwall.com oss-security (Nov 11)

Apache httpd 2.4.71: critical in mod_http2

On Nov 11, Apache released httpd 2.4.71. It fixes three flaws, one of them "critical": CVE-2026-119618, a race condition in assign_headers() in mod_http2 that, according to Apache, "can lead to RCE." Versions 2.4.55 through 2.4.70 are affected.[1] Also fixed are a crash in mod_md ("important") and a one-byte overflow in mod_vhost_alias ("low").[1] The critical flaw was found by Anthropic's OSS scanner and two researchers from Google Cloud, reported on Oct 26.[2] No attacks are known; Apache gives no CVSS score.

Race condition: Two parts of a program access the same memory at the same time, and the result depends on who gets there first. Like two people filling out the same form at once: in the end it holds a mix nobody wanted.
Our take Two independent HTTP/2 stacks on one day is no coincidence: scanner tools are getting better, and HTTP/2, with its per-stream state, is a rewarding target. If you cannot move httpd to 2.4.71, turn HTTP/2 off until then with Protocols http/1.1.
[1] httpd.apache.org (as of Nov 12) · [2] openwall.com oss-security (Nov 11)

Git: six flaws, seven releases

On Nov 10, the Git project released versions 2.50.2, 2.51.3, 2.52.1, 2.53.1, 2.54.1, 2.55.1 and 2.56.1 against six flaws. Versions older than 2.50 are also affected but no longer get an update.[1] The most important: a crafted repository can execute code during git clone --recurse-submodules (CVE-2026-111760). A heap overflow in the three-way merge (CVE-2026-105437) could lead to code execution, according to the GitLab advisory. Also included are a malicious server that can make a ref get written outside the target folder, and fast-import features that could read or write arbitrary files and are now off by default.[1] The advisory gives no CVSS scores. Its conclusion: "We highly recommend to upgrade."

Submodule: A Git repository that pulls other repositories in as subfolders. With a recursive clone, Git fetches them all. Like a package with more packages inside: you open one and get ten, some from senders you don't know.
Our take Locally the risk is small as long as you only clone your own repos. CI runners that recursively clone other people's repos are dangerous, for example for forks in pull requests. Check the Git version there first, and on self-hosted GitHub Actions runners too.
[1] openwall.com oss-security (Nov 11)

ScreenConnect: the remote-access tool as a weapon

Since the evening of Nov 11, ConnectWise has been investigating a campaign via ScreenConnect. Huntress first counted "6 compromised MSPs and 286+ endpoints, and those numbers are climbing," while BleepingComputer reports 47 affected organizations.[1] There is no flaw in the classic sense: Huntress calls it "abuse of legitimate functionality" via third-party extensions. ConnectWise has disabled five of them (Labtech Plus, RMM Plus, RMM+ and two Password-Link variants) in about 400 partner environments. On-premises customers have to do it themselves.[1]

MSP / RMM: A managed service provider looks after the IT of many small companies. For that it uses remote-management software (RMM) that runs on all customer PCs. Like a janitor service with a master key to a hundred houses: whoever takes over the janitor gets in everywhere.
Heads up Disabling the extensions does not remove malware that is already on the devices. ConnectWise advises checking login logs, the extensions' installation entries and the run-command history.[1]
[1] bleepingcomputer.com (Nov 11)

N-able: the hotfix is here

Update since Wed N-able is shipping N-central 2026.4 HF2. According to BleepingComputer, the hotfix fixes "some of the leaked zero-days," including XXE, OGNL injection, privilege escalation to root and an RCE via path traversal in file upload. All hosted servers are "successfully upgraded," says N-able; on-premises customers should catch up quickly. N-able reports no attacks, but Defused saw probing. Shadowserver counted just over 148 openly reachable N-central servers, down from 1,338 the day before.[1]

KEV: the first deadline expires today

Today, Nov 12, CISA's deadline ends for SSHole (CVE-2026-123158 in OpenSSH), GPUStack (CVE-2026-102895), FreeSwitch (CVE-2026-116779) and IBM Aspera Faspex (CVE-2026-123218). Tomorrow comes Barracuda ESG (CVE-2026-116606, CVE-2026-111560). SonicWall SSLVPN (CVE-2026-19868) is due on Nov 20, and Outlook, Chromium and Cisco BroadWorks on Nov 24.[1]

Nothing new on SSHole since Tuesday: affected is OpenSSH with musl libc, without PAM and with password login, so mainly Alpine; the fix is 10.6p2. According to GreyNoise there were 16 successful attack chains.[2]

Our take The KEV deadlines apply to US agencies, not to us. But they make a good order of priority. If you check only one thing today: old Alpine images with password login on SSH.

Cisco BroadWorks: old flaw, new attacker style

CVE-2026-20320 is an XXE flaw in the OCI-P interface of Cisco BroadWorks, a telephony platform for providers. "XML entries are improperly parsed due to external entity resolution being allowed by default," writes BleepingComputer. Cisco already patched it in August; since Nov 10 it has been in the KEV, deadline Nov 24.[1] New is the story behind it: according to Malbear Labs, a Chinese-speaking actor used an AI agent for the attacks, including against an EU telco and 13 other organizations.[1] That is a claim by a security vendor, not independent confirmation.

Our take Whether a human or an agent sends the requests changes nothing about the fix: a three-month-old patch has not been applied. The report gives no CVSS score or fixed version; we did not read the Cisco page. The assessment of AI agents as an attacker tool is covered in the AI briefs.

.NET 11: final, with C# 15

"The release of .NET 11.0 took place on November 10, 2026," writes heise. The version has Standard Term Support (STS) of 24 months and brings C# 15.0.[1] Visual Studio 2026 on the stable channel is now enough; the Insiders version is no longer needed.[1] According to Microsoft's blog, .NET 11 brings "faster developer tools, runtime and library improvements"; in RC1 the big language news was union types and closed class hierarchies.[2] The November servicing updates for the older versions arrived the same day.[2]

Union type: A type that has exactly one of several fixed forms, for example "success with a value" or "error with a reason." The compiler checks that you handle all cases. Like a parcel slip with exactly three boxes to tick: there is no fourth.
Our take Union types are what C# developers have been waiting for for years, and TypeScript and Java people already know the idea (sealed interfaces in Java). But STS means: if you want peace and quiet, stay on the LTS version and look at 11 in your next project. heise names no individual features; the details above come from the RC1 in September.

What Thursday is worth

Today, rebuild the base images with Node and check the Git version on the CI runners. If you run httpd with HTTP/2, move to 2.4.71. Old Alpine hosts with password login on SSH are today's first deadline. And PostgreSQL 14 gets its last release: after that, the upgrade is no longer a question.

It's Thursday, November twelfth. After the big Patch Tuesday, the quieter part came yesterday, and for developers it matters more: Node, Apache and Git all shipped security updates.

Node.js closes sixteen flaws, seven of them rated high. Most are in HTTP/2 and in TLS. One lets an attacker get around the client-certificate check. The new versions cover the twenty-two, twenty-four and twenty-six lines. Mainly affected is Node running as a server, not the local front-end build.

The Apache web server also has a critical flaw, in its HTTP/2 module. It can reach all the way to code execution. Version two point four point seventy-one fixes it. Two HTTP/2 stacks in one day: that's the attack surface of the week.

Git is shipping seven maintenance releases against six flaws. The most important one leads to code execution when you clone recursively with submodules. That hits CI runners in particular, the ones that clone other people's repositories.

With ScreenConnect, attackers are abusing third-party extensions. Huntress counts six affected IT service providers, BleepingComputer forty-seven organizations. ConnectWise has switched off five extensions. N-able, meanwhile, has a hotfix for its N-central platform.

Today the first deadline from the U.S. agency CISA runs out, among others for the OpenSSH flaw known as SSHole on Alpine systems. Barracuda follows tomorrow. In the Cisco BroadWorks case, a security vendor says an AI agent carried out the attacks. But the patch for it is already three months old.

On Patch Tuesday, a second look is worth it at a critical flaw in Windows Search. It's triggered through Exchange, and the recipient doesn't even have to open the email. Adobe closes five flaws in Connect with the top score of ten.

On releases: dot NET eleven is final, with C sharp fifteen and twenty-four months of support. And PostgreSQL fourteen gets its last release today.
